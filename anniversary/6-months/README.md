# 💜 6 Months with you — สมุดสติกเกอร์

เกมสมุดสติกเกอร์ครบรอบ 6 เดือน: เปิดปกสมุด → ลากสติกเกอร์ไปแต่งห้อง → แปะครบ 8 ชิ้น (หรือกด "เสร็จแล้ว 💜") → หน้าสุดท้ายมีกลอน + เสียงที่อัดไว้ + ปุ่มบันทึกภาพห้อง

## วิธีเปิด

**ดับเบิลคลิก `index.html`** ได้เลย ไม่มีขั้นตอน build ไม่มี framework

ข้อยกเว้นเดียว: ปุ่ม **บันทึกภาพ** ใช้ไม่ได้ตอนเปิดจากไฟล์ตรง ๆ (`file://`) เพราะเบราว์เซอร์ไม่ยอมให้อ่าน canvas
ต้องเปิดผ่านเว็บจริงหรือเซิร์ฟเวอร์ในเครื่อง:

```bash
python -m http.server 8000     # แล้วเปิด http://localhost:8000
```

## วิธีเล่น

- ลากสติกเกอร์จากถาดไปแปะในห้อง / ลากย้ายได้ / ตัวที่แปะทีหลังอยู่บนสุด
- แตะสติกเกอร์ = เด้งดุ๊กดิ๊ก (ตัวที่มีชิบิจะร้องเหมียว)
- กดค้าง หรือ ลากกลับลงถาด = เก็บคืนถาด
- เพลงคลอเริ่มตอนเปิดปก และปิดเองเมื่อพลิกไปหน้าสุดท้าย (กลับมาเล่นต่อเมื่อกดกลับไปแปะ)
- 🔊 เปิด/ปิดเสียงเอฟเฟกต์และเพลง · 🧹 ล้างเริ่มใหม่ (มีถามยืนยัน)
- ตำแหน่งสติกเกอร์จำไว้ใน localStorage ของเครื่องนั้น

## แก้ตรงไหน

| อยากแก้ | ไฟล์ |
|---|---|
| กลอน, ข้อความบนปก, ข้อความปุ่ม | `index.html` (แก้ตัวหนังสือได้ตรง ๆ) |
| รายการสติกเกอร์ + ขนาดแต่ละชิ้น (`w`) | `STICKERS` บนสุดของ `anniversary.js` |
| จำนวนชิ้นที่ถือว่าครบ | `GOAL` ใน `anniversary.js` |
| ความเร็วพิมพ์กลอน | `CHAR_MS`, `LINE_PAUSE` ใน `anniversary.js` |
| หน้าตาห้อง | `buildRoomSvg()` ใน `anniversary.js` |
| สี / ฟอนต์ | `:root` ใน `anniversary.css` |

แก้ css หรือ js แล้วอย่าลืมเพิ่มเลข `?v=` ใน `index.html` (กัน cache ของ GitHub Pages)

## โครงไฟล์

```
index.html              โครงหน้า + ข้อความทั้งหมด
anniversary.css         สไตล์และ animation
anniversary.js          เกม, เสียง (Web Audio), ห้อง isometric (SVG)
assets/stickers/        สติกเกอร์ตัวละคร 8 ชิ้น
assets/decor/           สติกเกอร์ของตกแต่ง 9 ชิ้น
assets/audio/           voice.mp3 (+ voice.m4a สำรอง), bgm.mp3 = เพลงคลอ
```
