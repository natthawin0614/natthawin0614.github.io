## วิธีเปิด

**ดับเบิลคลิกไฟล์ `index.html`** ได้เลย ไม่ต้องติดตั้งอะไรทั้งนั้น
(หน้าเว็บเป็นไฟล์ static ล้วน ๆ ไม่มีขั้นตอน build — GSAP ถูกเก็บไว้ใน `vendor/` แล้ว)

ถ้าอยากเปิดผ่านเซิร์ฟเวอร์ (เช่นจะเทสต์บนมือถือในวง Wi-Fi เดียวกัน):

```bash
npx serve .
```

## เปลี่ยน / เพิ่มรูป

รูปอยู่ใน `media/photos/` (ย่อไว้แล้วเหลือ 1.2 MB จากต้นฉบับ 13.6 MB)

ตำแหน่งรูปแต่ละใบคุมด้วย custom property ใน `index.html`:

```html
<figure class="pola" style="--x:30%; --y:46%; --r:-7deg; --z:1">
```

- `--x` / `--y` — ตำแหน่งบนกอง (% ของเวที)
- `--r` — องศาเอียง
- `--z` — ใบไหนทับใบไหน (เลขมากอยู่บน)

ส่วนแอนิเมชันบินเข้า–บินออกคำนวณเองใน `anniversary.js` ไม่ต้องแก้อะไร
