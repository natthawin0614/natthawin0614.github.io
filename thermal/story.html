8 บท · เรื่องเดียวต่อกันตั้งแต่ต้นจนจบ

ทั้งวิชานี้คือเรื่องเล่าเรื่องเดียว

ทุกบทเกิดขึ้นเพราะบทก่อนหน้าตอบคำถามบางอย่างไม่ได้ — อ่านเรียงจากบนลงล่างครั้งเดียว แล้วสูตรทั้ง 33 อันจะเข้าที่เอง เพราะคุณจะรู้ว่าแต่ละอันเกิดมาเพื่อแก้ปัญหาอะไร

ความคืบหน้า 0 / 0

โครงเรื่องทั้งหมดใน 8 บรรทัด
① “ร้อน” วัดยังไง → ได้ T (กฎข้อ 0) ② ความร้อนคืออะไร → ได้ U, Q, W (กฎข้อ 1) ③ แล้ว W คิดยังไง → ได้ W = −∫P dV (แตกเป็น 4 กรณี) ④ แล้ว U คิดยังไง → ได้ U = (f/2)nRT (equipartition) ⑤ แก๊สอุดมคติโกหกตอนไหน → ได้ Z, van der Waals ⑥ ถ้ามันกลายเป็นของเหลว → ได้ ตาราง, x, H ⑦ ทำไมธรรมชาติเดินทางเดียว → ได้ S (กฎข้อ 2) ⑧ แล้วสร้างเครื่องยนต์ได้แค่ไหน → ได้ η, COP

แต่ละลูกศรคือ “คำถามที่บทก่อนหน้าตอบไม่ได้” — นั่นคือกาวที่เชื่อมทั้งวิชา

แล้วกฎ 3 ข้ออยู่ตรงไหนของเรื่อง
กฎข้อ 0 → บทที่ 1 ตอบว่า "อุณหภูมิมีความหมายได้ยังไง" กฎข้อ 1 → บทที่ 2–6 ตอบว่า "พลังงานมีเท่าไหร่" กฎข้อ 2 → บทที่ 7 ตอบว่า "พลังงานไปทางไหน"

สังเกตว่ากฎข้อ 1 กินพื้นที่ถึง 5 บท — เพราะ ΔU = Q + W ตั้งไว้ในบทที่ 2 แต่ยังเติมตัวเลขไม่ได้ ต้องใช้อีก 4 บทมาสอนวิธีเติม:

บท 2 → ΔU = Q + W ตั้งสมการ (นี่คือตัวกฎข้อ 1) บท 3 → แล้ว W คิดยังไง เติมตัวเลขลงช่อง W บท 4 → แล้ว U คิดยังไง เติมตัวเลขลงช่อง ΔU บท 5 → ถ้าไม่ใช่แก๊สอุดมคติล่ะ ซ่อมวิธีเติม บท 6 → ถ้าเป็นน้ำ/ไอน้ำล่ะ เปิดตารางมาเติมแทน

บท 3–6 ไม่มีกฎใหม่เลยสักข้อ ทั้งหมดคือ “วิธีหาตัวเลขมาใส่ในสมการของบทที่ 2” · ส่วนกฎข้อ 2 ใช้บทเดียวจบ เพราะมันบอกแค่เรื่องเดียวคือทิศทาง

บทที่ 1

เริ่มจากปัญหา: “ร้อน” มันวัดยังไง

ปัญหา

เราเอามือแตะของแล้วรู้สึกร้อนหรือเย็น แต่ความรู้สึกเชื่อไม่ได้ — จับเหล็กกับจับไม้ที่อุณหภูมิเดียวกัน ยังรู้สึกไม่เท่ากันเลย แล้วเราจะนิยาม “ความร้อน–เย็น” ให้เป็นวิทยาศาสตร์ได้ยังไง

สิ่งที่สังเกตได้

เอาของสองอย่างมาแตะกันนาน ๆ สมบัติของมันจะหยุดเปลี่ยน — เรียกสภาวะนั้นว่า สมดุลทางความร้อน (ไม่มีการถ่ายเทความร้อนสุทธิระหว่างกัน แม้ยังสัมผัสกันอยู่)

แล้วมีข้อเท็จจริงหนึ่งที่ดูธรรมดามากแต่สำคัญมหาศาล: ถ้า A สมดุลกับ C และ B สมดุลกับ C แล้ว A จะสมดุลกับ B ด้วยเสมอ — สมบัตินี้เรียกว่า “ถ่ายทอดได้” (transitive)

กฎข้อที่ศูนย์ · และทำไมมันถึงสำคัญกว่าที่คิด

ความ “ถ่ายทอดได้” นี่แหละที่ทำให้เทอร์โมมิเตอร์ใช้งานได้ — เราเอาเทอร์โมมิเตอร์ (C) ไปแตะกาแฟ (A) แล้วเอาไปแตะซุป (B) ถ้าอ่านค่าเท่ากัน เราสรุปได้เลยว่ากาแฟกับซุปอุณหภูมิเท่ากัน โดยไม่ต้องเอามันมาแตะกันจริง ๆ

ถ้าธรรมชาติไม่มีสมบัติข้อนี้ การวัดอุณหภูมิจะไม่มีความหมายเลย → นี่คือเหตุผลที่มันได้เป็น “กฎ” และเป็นเหตุผลที่มันต้องมาก่อนกฎข้ออื่น จึงเรียกว่าข้อที่ศูนย์

🎁 ได้อะไรจากบทนี้T (อุณหภูมิ) — ตัวแปรตัวแรกของวิชา · และกฎเหล็กว่าสูตรทุกสูตรต่อจากนี้ใช้เคลวิน
→ ปัญหาใหม่ที่ตามมา

ตอนนี้เราวัดอุณหภูมิได้แล้ว แต่ยังไม่รู้ว่าตอนของร้อนแตะของเย็น มีอะไรไหลข้ามไป และมันคืออะไร — ไปบทที่ 2

บทที่ 2

ความร้อนไม่ใช่ “ของ” แต่เป็น “การเดินทาง”

ความเข้าใจผิดในอดีต

คนสมัยก่อนคิดว่าความร้อนคือของเหลวล่องหนชื่อ caloric ที่บรรจุอยู่ในวัตถุ ของร้อนมีเยอะ ของเย็นมีน้อย พอแตะกันมันก็ไหลจากมากไปน้อย — ฟังดูสมเหตุสมผลมาก

แต่จูลทำการทดลองที่ล้มความคิดนี้: เอาใบพัดกวนน้ำในถังปิด ไม่มีความร้อนเข้าไปเลยสักนิด มีแต่งานล้วน ๆ — แต่น้ำร้อนขึ้นจริง

ข้อสรุปที่เปลี่ยนทั้งวิชา

ถ้างานทำให้ร้อนขึ้นได้เหมือนความร้อน แปลว่าทั้งสองอย่างไม่ใช่ “สาร” ที่เก็บอยู่ในวัตถุ แต่เป็น ช่องทางถ่ายเทพลังงาน 2 ช่องทาง ที่แลกเปลี่ยนกันได้

สิ่งที่เก็บอยู่จริงในวัตถุคือ U — พลังงานภายใน (ผลรวมพลังงานจลน์และศักย์ของโมเลกุลทุกตัว)

ความแตกต่างที่ต้องแยกให้ขาด — ข้อสอบทฤษฎีถามตรงนี้
U = สิ่งที่วัตถุ "มี" → ขึ้นกับสถานะปัจจุบันเท่านั้น Q, W = สิ่งที่ "เกิดขึ้น" ระหว่างทาง → ขึ้นกับเส้นทางที่เดิน

เปรียบเทียบ: U เหมือนยอดเงินในบัญชี · Q กับ W เหมือนการโอนเข้า–โอนออก · คุณถามได้ว่า “ตอนนี้มีเงินเท่าไหร่” แต่ถามว่า “ตอนนี้มีการโอนเท่าไหร่” ไม่ได้ — นี่คือเหตุผลที่เขียน δQ, δW ไม่ใช่ dQ, dW และคือความหมายของคำว่า state function กับ path function

กฎข้อที่หนึ่ง — แค่การอนุรักษ์พลังงาน เขียนใหม่
ΔU = Q + W
ตัวแปรคืออะไรเครื่องหมายบวกแปลว่า
ΔUพลังงานภายในที่เปลี่ยนไประบบมีพลังงานมากขึ้น (มักแปลว่าร้อนขึ้น)
Qความร้อนที่ถ่ายเทเพราะผลต่างอุณหภูมิความร้อนเข้าระบบ
Wงานที่ถ่ายเทเพราะแรงกระทำผ่านระยะทางสิ่งแวดล้อมทำงานต่อระบบ (แก๊สถูกอัด)

อ่านเป็นภาษาคน: “พลังงานที่ระบบมีเพิ่มขึ้น = ที่ได้มาทางความร้อน + ที่ได้มาทางงาน” — ไม่มีอะไรลึกลับเลย พลังงานเข้าออกได้แค่ 2 ประตูนี้เท่านั้นสำหรับระบบปิด

🎁 ได้อะไรจากบทนี้U, Q, W และสมการ ΔU = Q + W · พร้อมความเข้าใจว่าทำไม Q กับ W ถึงไม่ใช่ “ของที่มีอยู่”
→ ปัญหาใหม่ที่ตามมา

สมการนี้มี 3 ตัวแปร แต่เรายังคำนวณ W กับ U ไม่เป็นสักตัว — ต้องหาวิธีคิดทั้งคู่ ไปบทที่ 3 (คิด W) แล้วบทที่ 4 (คิด U)

บทที่ 3

คิด W ยังไง — และทำไมสูตรงานถึงมีตั้ง 4 อัน

เริ่มจากนิยามงานที่เรียนมาตั้งแต่กลศาสตร์

งาน = แรง × ระยะทาง แต่กับแก๊สเราไม่รู้ “แรง” เรารู้ ความดัน — เลยต้องแปลง

F = P·A และ A·dx = dV dW = F dx = P·A·dx = P dV จึงได้ W = − ∫ P dV

ทำไมมีเครื่องหมายลบ: เพราะเราตกลงกันว่า W คืองานที่ทำต่อระบบ — ถ้าแก๊สขยายตัว (dV เป็นบวก) แปลว่าแก๊สไปผลักสิ่งแวดล้อม คือเสียพลังงานออกไป W จึงต้องติดลบ

🔑 นี่คือคำตอบว่าทำไมสูตรงานถึงมีหลายอัน

จะอินทิเกรต ∫P dV ได้ ต้องรู้ว่า P เปลี่ยนไปยังไงเมื่อ V เปลี่ยน — ซึ่งขึ้นกับว่ากระบวนการนั้นเป็นแบบไหน
เราจึงไม่ได้มีสูตรงาน 4 สูตร — เรามีสูตรเดียว แค่อินทิเกรตภายใต้เงื่อนไข 4 แบบ

อินทิเกรตทีละกรณี
P คงที่ (isobaric) — ดึง P ออกนอกอินทิกรัลได้เลย W = −P ∫dV = −P ΔV V คงที่ (isochoric) — dV = 0 ทั้งหมด W = 0 → ΔU = Q ทั้งดุ้น T คงที่ (isothermal) — แทน P = nRT/V เข้าไป แล้ว ∫dV/V = ln W = −nRT ∫dV/V = −nRT ln(V_f/V_i) Q = 0 (adiabatic) — ต้องหาความสัมพันธ์ P–V ใหม่ก่อน ได้ PV^γ = const W = (P_f V_f − P_i V_i)/(γ−1) และ ΔU = W ทั้งดุ้น
ความหมายเชิงกราฟ — ประโยคเดียวที่ครอบทุกกรณี

∫P dV คือพื้นที่ใต้กราฟ P–V · ทั้ง 4 สูตรข้างบนคือ “พื้นที่ใต้กราฟที่มีรูปร่างต่างกัน” · ถ้าโจทย์ให้กราฟมาแต่ไม่เข้ากรณีไหนเลย → หาพื้นที่ตรง ๆ ก็ได้คำตอบเหมือนกัน
และถ้าเดินครบวงปิด พื้นที่ที่ล้อมรอบ = งานสุทธิต่อรอบ ← ตัวนี้จะกลับมาสำคัญมากในบทที่ 8

🎁 ได้อะไรจากบทนี้คิด W เป็นแล้วทุกกรณี · และเข้าใจว่าคำถามแรกที่ต้องถามทุกข้อคือ “อะไรคงที่ในกระบวนการนี้”
บทที่ 4

คิด U ยังไง — ต้องลงไปดูระดับโมเลกุล

ปัญหา

U คือผลรวมพลังงานของโมเลกุลทุกตัว ในแก๊ส 1 โมลมี 6×10²³ ตัว — นับทีละตัวเป็นไปไม่ได้ ต้องใช้สถิติ

ทางออก: ทฤษฎีบท Equipartition

ธรรมชาติแบ่งพลังงานเฉลี่ยเท่า ๆ กันให้ทุก “ช่องทางที่โมเลกุลเก็บพลังงานได้” — เรียกช่องทางเหล่านี้ว่า degree of freedom (dof) และแต่ละช่องได้ ½kT เท่ากันหมด

U = (f/2) N k T = (f/2) n R T f = จำนวน dof ทั้งหมด
โมเลกุลเก็บพลังงานได้ทางไหนบ้างf
อะตอมเดี่ยว (He)วิ่งได้ 3 แกน (x, y, z)3
ไดอะตอมิก (N₂) ที่ T ปกติวิ่ง 3 + หมุนได้ 2 แกน5
ไดอะตอมิกที่ T สูงมากวิ่ง 3 + หมุน 2 + สั่น 27

ทำไมการสั่นนับเป็น 2: เพราะสปริงพันธะมีทั้งพลังงานจลน์และพลังงานศักย์ (E = ½μẋ² + ½kx² — สองพจน์กำลังสอง) ส่วนการวิ่งกับการหมุนมีแค่พจน์จลน์อย่างเดียว

🔑 ผลลัพธ์ที่สำคัญที่สุดของบทนี้

ในสมการ U = (f/2)nRT ไม่มี V และไม่มี P อยู่เลย → แปลว่าสำหรับแก๊สอุดมคติ U ขึ้นกับ T อย่างเดียว

ΔU = n C_v ΔT ใช้ได้กับทุกกระบวนการ ไม่ใช่แค่ V คงที่

เห็น Cv แล้วอย่านึกว่าใช้ได้แค่ isochoric — ใช้ได้หมด ทั้ง isobaric, isothermal, adiabatic เพราะ U สนใจแค่ว่า T เปลี่ยนไปเท่าไหร่ ไม่สนว่าเดินทางมาแบบไหน (U เป็น state function นั่นเอง)

แล้ว C_p โผล่มาจากไหน

ถ้าให้ความร้อนตอน V คงที่ — พลังงานทั้งหมดไปเพิ่ม T อย่างเดียว
ถ้าให้ความร้อนตอน P คงที่ — แก๊สต้องขยายตัวดันสิ่งแวดล้อมไปด้วย พลังงานส่วนหนึ่งจึงถูกใช้ไปกับงาน เหลือไปเพิ่ม T น้อยลง
→ ต้องใส่ความร้อนมากกว่าเพื่อให้ได้ ΔT เท่ากัน → C_p > C_v เสมอ และส่วนต่างพอดีเท่ากับงานขยายตัว: C_p − C_v = R

🎁 ได้อะไรจากบทนี้U = (f/2)nRT · ΔU = nC_vΔT · C_p − C_v = R · γ = C_p/C_v (ตัวที่ไปโผล่ในสูตรอะเดียแบติกบทที่แล้ว)
→ ปัญหาใหม่ที่ตามมา

ทุกอย่างข้างบนตั้งอยู่บน PV = nRT ซึ่งเป็นแบบจำลองที่สมมติว่าโมเลกุลไม่มีขนาดและไม่ดึงดูดกัน — แต่ของจริงไม่ใช่แบบนั้น มันพังตอนไหน ไปบทที่ 5

บทที่ 5

แก๊สอุดมคติโกหกตอนไหน

สมมติฐานที่ซ่อนอยู่ใน PV = nRT

① โมเลกุลไม่มีปริมาตร (เป็นจุด)  ② โมเลกุลไม่มีแรงกระทำต่อกัน ยกเว้นตอนชน
ทั้งสองข้อนี้จริงพอใช้ได้ตอนแก๊สเจือจาง — โมเลกุลอยู่ห่างกันมากจนขนาดตัวเองและแรงดึงดูดไม่สำคัญ

แล้วมันพังเมื่อไหร่
ความดันสูง → โมเลกุลถูกบีบให้อยู่ใกล้กัน → ปริมาตรของตัวมันเองเริ่มมีผล อุณหภูมิต่ำ → โมเลกุลวิ่งช้าลง → แรงดึงดูดเริ่มชนะการเคลื่อนที่
3 วิธีรับมือ — เรียงจากขี้เกียจที่สุดไปละเอียดที่สุด

① วัดความผิดพลาดตรง ๆ ไม่ต้องแก้สมการ

Z = P v / (R T) Z = 1 คืออุดมคติพอดี · Z ห่างจาก 1 เท่าไหร่ = ผิดเท่านั้น

แล้วพบเรื่องน่าทึ่ง: แก๊สทุกชนิดมีค่า Z ใกล้เคียงกัน ถ้าเทียบที่ความดันและอุณหภูมิเป็นสัดส่วนกับจุดวิกฤตของตัวเอง (P_R = P/P_cr, T_R = T/T_cr) → เลยใช้แผนภูมิเดียวได้กับทุกแก๊ส เรียกว่าหลักสถานะสมนัย

② แก้สมการให้สมจริงขึ้น — van der Waals

( P + a/v² )( v − b ) = R T a/v² ชดเชยที่ แรงดึงดูด ทำให้ความดันจริงต่ำกว่าอุดมคติ (จึงบวกคืน) −b ชดเชยที่ โมเลกุลกินที่ ที่ว่างจริงจึงน้อยกว่า v (จึงลบออก)

③ ไม่แก้ แต่กางเป็นอนุกรม — วิเรียล

Pv/RT = 1 + B(T)/v + C(T)/v² + … B < 0 → แรงดึงดูดเด่น (เกิดที่ T ต่ำ) · B > 0 → แรงผลักเด่น (T สูง)

เมื่อสารเปลี่ยนเฟส — สมการล่มสลาย ต้องใช้ตาราง

พลังงานที่ใส่เข้าไปไม่ได้ไปเพิ่มความเร็วโมเลกุล (ซึ่งคือสิ่งที่ T วัด) แต่ไปดึงโมเลกุลออกจากกัน ทำลายแรงยึดเหนี่ยวเพื่อให้หลุดจากของเหลวกลายเป็นไอ → เรียกว่า ความร้อนแฝง (latent = แฝงอยู่ ไม่แสดงออกทางอุณหภูมิ) → Q = mL

ปัญหาที่ 2 — ระหว่างนั้น P กับ T ไม่เป็นอิสระต่อกันแล้ว

ปกติเราระบุสถานะแก๊สด้วย 2 ตัวแปรอิสระ (เช่น P กับ T) แล้วหาที่เหลือได้ — แต่ในโดมของผสม P กับ T จับคู่กันตายตัว (น้ำเดือดที่ 1 atm ต้องเป็น 100 °C เสมอ) รู้ P ก็รู้ T ทันที ไม่ได้ข้อมูลเพิ่ม

→ ต้องมีตัวแปรใหม่มาบอกว่า “ตอนนี้กลายเป็นไอไปแล้วกี่เปอร์เซ็นต์”

x = m_ไอ / m_รวม 0 ≤ x ≤ 1 แล้วทุกสมบัติหาได้จาก x ตัวเดียว : v = v_f + x·v_fg u = u_f + x·u_fg h = h_f + x·h_fg
ปัญหาที่ 3 — และมันไม่มีสมการ

พฤติกรรมของน้ำในบริเวณนี้ซับซ้อนเกินกว่าจะเขียนเป็นสมการเดียวได้ → นักวิทยาศาสตร์เลยวัดจากการทดลองแล้วทำเป็นตาราง (A-4 ถึง A-7)
นี่คือคำตอบว่าทำไมบทนี้ต้องเปิดตารางแทนการแทนสูตร ไม่ใช่เพราะอาจารย์อยากให้ลำบาก แต่เพราะมันไม่มีสูตรให้แทนจริง ๆ

ของแถมจากบทนี้: เอนทัลปี H
H = U + P V ที่ P คงที่ : ΔH = Q

เพราะกระบวนการในชีวิตจริงส่วนใหญ่เกิดที่ความดันบรรยากาศคงที่ (ต้มน้ำ หายใจ เครื่องยนต์) เลยรวม “พลังงานภายใน + งานขยายตัว” เป็นตัวเดียวไปเลย จะได้ไม่ต้องแยกคิดทุกครั้ง → นี่คือเหตุผลที่ตารางให้ค่า h มาให้ใช้ตรง ๆ

บทที่ 7

คำถามที่กฎข้อ 1 ตอบไม่ได้ → จึงต้องมี S

🔑 ปัญหาที่นำไปสู่เอนโทรปี

ลองเทียบสองเหตุการณ์นี้:

① กาแฟร้อนวางไว้ในห้อง แล้วมันเย็นลง → พลังงานสมดุล ✓ เกิดขึ้นจริงทุกวัน ② กาแฟเย็นวางไว้ในห้อง แล้วมันร้อนขึ้นเอง โดยดูดความร้อนจากอากาศ → พลังงานสมดุล ✓ แต่ไม่เคยเกิดเลย

กฎข้อ 1 อนุญาตทั้งคู่เท่ากัน เพราะพลังงานรวมเท่าเดิมทั้งสองกรณี → แปลว่ากฎข้อ 1 อธิบาย “ทิศทาง” ของธรรมชาติไม่ได้
เราจึงต้องการปริมาณใหม่ที่ทำหน้าที่ชี้ทิศ — นั่นคือ S

เอนโทรปีคืออะไรจริง ๆ — มองแบบสถิติเข้าใจง่ายที่สุด
S = k ln Ω Ω = จำนวนวิธีจัดเรียงระดับโมเลกุล ที่ให้ผลหน้าตาเหมือนกันในระดับที่เรามองเห็น

ตัวอย่างที่เห็นภาพ: โยนเหรียญ 100 เหรียญ — “หัวทั้ง 100” มีวิธีเดียว แต่ “หัว 50 ก้อย 50” มีวิธีเป็นล้านล้านแบบ → เวลาโยนจึงได้ประมาณ 50-50 แทบทุกครั้ง ไม่ใช่เพราะมีแรงบังคับ แต่เพราะมันมีวิธีเกิดมากกว่ามหาศาล

แก๊สที่กระจายเต็มห้องก็เหมือนกัน — มันไม่ได้ “ถูกผลัก” ให้กระจาย แต่สถานะกระจายมีจำนวนวิธีเกิดมากกว่าสถานะที่กระจุกอยู่มุมเดียวอย่างเทียบไม่ได้ ธรรมชาติเดินทางเดียวเพราะความน่าจะเป็น ไม่ใช่เพราะแรง

นิยามเชิงอุณหพลศาสตร์ — รูปที่ใช้คำนวณจริง
dS = δQ_rev / T ΔS = ∫ δQ_rev / T

ทำไมต้องหารด้วย T: ให้ความร้อน 1 J กับของที่เย็นจัด (โมเลกุลนิ่ง ๆ) จะทำให้ความปั่นป่วนเพิ่มขึ้นเยอะ · แต่ให้ 1 J เท่ากันกับของที่ร้อนจัดอยู่แล้ว (ปั่นป่วนอยู่แล้ว) เพิ่มขึ้นนิดเดียว → ผลของความร้อนจึงต้องหารด้วยอุณหภูมิที่มีอยู่เดิม

กฎข้อที่สอง — 3 รูป พูดเรื่องเดียวกัน
รูปเอนโทรปี ΔS_รวม ≥ 0 (= reversible · > irreversible) Clausius ความร้อนไม่ไหลจากเย็นไปร้อนเองโดยไม่มีงานภายนอก Kelvin–Planck ไม่มีเครื่องยนต์ใดเปลี่ยนความร้อนเป็นงานได้ 100%

ทั้งสามเทียบเท่ากัน — ถ้าละเมิดข้อใดข้อหนึ่ง จะละเมิดอีกสองข้อโดยอัตโนมัติ

🔑 จุดที่ยากที่สุดของทั้งวิชา — และเป็นตัวเก็งข้อสอบ

dS = δQ_rev/T มีคำว่า rev ห้อยอยู่ แปลว่าใช้ได้เฉพาะกระบวนการ ผันกลับได้ — แต่กระบวนการจริงทุกอันเป็น irreversible แล้วจะคำนวณยังไง

ทางออก: เพราะ S เป็น state function (ขึ้นกับสถานะ ไม่ขึ้นกับเส้นทาง — แนวคิดเดียวกับ U ในบทที่ 2) เราจึงสมมติเส้นทาง reversible ขึ้นมาใหม่ที่เชื่อมสถานะเริ่มต้นกับสถานะสุดท้ายอันเดียวกัน แล้วคำนวณบนเส้นทางสมมตินั้น — ได้ ΔS เท่ากันเป๊ะ

ตัวอย่างคลาสสิก — ขยายสู่สุญญากาศ: W = 0 (ไม่มีอะไรให้ดัน), Q = 0 (หุ้มฉนวน), ΔU = 0, T ไม่เปลี่ยน
ถ้าใส่ Q = 0 ตรง ๆ จะได้ ΔS = 0 ซึ่งผิด → ต้องสมมติเป็นการขยายตัวแบบ isothermal ที่ช้า ๆ แทน แล้วได้ ΔS = nR ln(V_f/V_i) > 0 ✓

🎁 ได้อะไรจากบทนี้S · ΔS ≥ 0 · และเหตุผลว่าทำไมสูตร ΔS ถึงมี ln ทุกอัน (เพราะมาจาก ∫dQ/T ที่ T หรือ V เปลี่ยน → อินทิเกรตแล้วได้ ln)

η = W_net/Q_H = 1 − Q_C/Q_H < 1 เสมอ ขีดจำกัดสูงสุด (คาร์โนต์) : η = 1 − T_C/T_H ← เพราะเป็นวัฏจักรที่ผันกลับได้ทั้งหมด ΔS_รวม = 0 พอดี ดีกว่านี้ไม่ได้แล้ว ← ประกอบด้วย isothermal 2 + adiabatic 2 (สองกระบวนการจากบทที่ 3) กลับด้านเครื่องยนต์ = ตู้เย็น (ใส่งานเพื่อดันความร้อนย้อนทาง) COP_R = Q_C/W COP_HP = Q_H/W = COP_R + 1
