สูตรเขียนคำตอบ 5 ขั้น — ใช้ได้ทุกข้อ

ถอดจากคำตอบ QUIZ-01 ที่คุณเขียนเอง ซึ่งวางโครงมาถูกแล้ว

① ลากเส้นว่า “ระบบ” คืออะไร
เขียนออกมาเป็นตัวอักษรเลย เช่น “ระบบ = ห้องทั้งห้อง (คน + จักรยาน + อากาศ)” — ขั้นนี้ได้คะแนนแน่นอน และเป็นตัวตัดสินคำตอบทั้งข้อ
↓
② แปลเงื่อนไขในโจทย์เป็นสัญลักษณ์
“หุ้มฉนวน” → Q = 0 · “ผนังแข็ง” → W = 0 · “ครบรอบ” → ΔU = 0
↓
③ เขียนกฎที่ใช้ แล้วแทนเงื่อนไขลงไป
ΔU = Q + W = 0 หรือ ΔS_รวม ≥ 0 — เขียนสมการจริง ไม่ใช่บรรยายลอย ๆ
↓
④ ไล่ว่าพลังงาน (หรือเอนโทรปี) ไปไหนบ้าง
เขียนเป็นลูกศรต่อกัน: เคมี → กล → เสียดทาน → ความร้อน → อากาศ
↓
⑤ ชี้ว่าเขาสับสนระหว่าง “A” กับ “B”
ประโยคทองคือ “เขาสับสนระหว่าง ___ กับ ___” — ขั้นนี้คือหัวใจของคะแนน
ขั้นที่ ⑤ คือขั้นที่แยกคะแนนเต็มออกจากคะแนนครึ่ง

คำตอบ QUIZ-01 ของคุณจบด้วย “เพื่อนสับสนระหว่าง จักรยานไม่เคลื่อนที่ข้ามห้อง กับ ไม่มีพลังงานเปลี่ยนรูป” — นี่คือรูปประโยคที่ถูกต้องเป๊ะ · ทุกข้อเก็งด้านล่างผมเขียนประโยคนี้ไว้ให้แล้ว ฝึกพูดออกมาให้ได้ ไม่ต้องท่องคำต่อคำ

7 ข้อเก็ง

เรียงตามโอกาสออก

⭐⭐⭐เก็ง 1 · เครื่องยนต์ประสิทธิภาพ 100%กฎข้อ 2 · เอนโทรปี
โจทย์ที่เก็งนักประดิษฐ์คนหนึ่งอ้างว่าสร้างเครื่องยนต์ที่รับความร้อน 1000 J จากอ่างร้อนที่ 500 K แล้วเปลี่ยนเป็นงานได้ 1000 J ทั้งหมด โดยไม่ทิ้งความร้อนลงอ่างเย็นเลย
(a) เครื่องนี้ขัดกับกฎข้อที่หนึ่งหรือไม่  (b) ขัดกับกฎข้อที่สองหรือไม่ จงอธิบายด้วยเอนโทรปี  (c) ถ้ามีอ่างเย็นที่ 300 K งานสูงสุดที่เป็นไปได้จริงคือเท่าไหร่
(a) กฎข้อที่หนึ่ง — ไม่ขัด

พลังงานเข้า 1000 J ออกเป็นงาน 1000 J สมดุลพอดี · เครื่องยนต์ทำงานครบรอบ ΔU = 0 → Q_net = −W_net ✓
ประเด็นสำคัญ: กฎข้อที่หนึ่งอนุญาตให้เครื่องนี้มีอยู่ได้ — นี่คือเหตุผลว่าทำไมเราถึงต้องมีกฎข้อที่สอง

(b) กฎข้อที่สอง — ขัดเต็ม ๆ
อ่างร้อนเสียความร้อน ΔS_H = −1000/500 = −2 J/K งานเป็นพลังงานที่เป็นระเบียบ ไม่มีเอนโทรปี ΔS_งาน = 0 ไม่มีอ่างเย็น ΔS_C = 0 ΔS_รวม = −2 J/K < 0 → เป็นไปไม่ได้

และนี่คือการละเมิด Kelvin–Planck statement โดยตรง: “ไม่มีเครื่องยนต์วัฏจักรใดที่รับความร้อนจากอ่างเดียวแล้วเปลี่ยนเป็นงานได้ทั้งหมด”

(c) ขีดจำกัดจริง
η_max = 1 − T_C/T_H = 1 − 300/500 = 40% W_max = (0.40)(1000) = 400 J ต้องทิ้ง Q_C = 600 J ตรวจสอบ : ΔS = −1000/500 + 600/300 = −2 + 2 = 0 ✓ เท่ากับศูนย์พอดี = reversible = คาร์โนต์ ดีกว่านี้ไม่ได้แล้ว
🔍 ขยาย — ΔS = −1000/500 + 600/300 มาจากไหน

เป็นการบวก ΔS ของทุกส่วนที่เกี่ยวข้อง ไม่ใช่แค่ของเครื่องยนต์:

ΔS_รวม = ΔS_อ่างร้อน + ΔS_อ่างเย็น + ΔS_เครื่องยนต์ อ่างร้อน (500 K) ความร้อนออก 1000 J → −1000/500 = −2 J/K อ่างเย็น (300 K) ความร้อนเข้า 600 J → +600/300 = +2 J/K เครื่องยนต์ ครบรอบ กลับสถานะเดิม → 0 (S เป็น state function) งาน 400 J พลังงานที่เป็นระเบียบ → 0 (งานไม่พกเอนโทรปี)

ทำไมใช้ Q/T เฉย ๆ ไม่ต้องอินทิเกรตเป็น ln: เพราะ “อ่างความร้อน” นิยามว่าใหญ่มากจน T ไม่เปลี่ยนเลย จึงดึง T ออกนอกอินทิกรัลได้ ΔS = (1/T)∫δQ = Q/T · ต่างจากโจทย์ทังสเตนร้อนขึ้นที่ T เปลี่ยนจริง จึงต้องใช้ mc ln(T_f/T_i)

🔑 แก่นของเรื่อง: ความร้อนพกเอนโทรปีมาด้วย งานไม่พก → เครื่องยนต์ที่ดูดความร้อนเข้ามา (พา S เข้ามา) แล้วปล่อยออกแต่งาน (ไม่พา S ออกไป) จะทำให้ S หายไปเฉย ๆ ซึ่งเป็นไปไม่ได้ · เครื่องยนต์จึงต้องทิ้งความร้อนบางส่วน เพื่อ “ระบายเอนโทรปี” ออกไป ไม่ใช่เพราะวิศวกรทำไม่เก่งพอ

เทียบ 3 กรณีให้เห็นว่า ΔS = 0 คือเส้นแบ่ง
เครื่องปลอม 100% ΔS = −1000/500 + 0 = −2 J/K ✗ ติดลบ = เป็นไปไม่ได้ ↑ ไม่มีอ่างเย็นให้ระบาย S คาร์โนต์ ΔS = −1000/500 + 600/300 = 0 J/K ✓ พอดีเป๊ะ = ดีที่สุดที่ทำได้ เครื่องจริง ΔS = −1000/500 + 700/300 = +0.33 ✓ เกิดได้ แต่ได้งานแค่ 300 J ↑ ทิ้งความร้อนมากกว่า = แย่กว่า
🎁 จากตรงนี้พิสูจน์สูตรคาร์โนต์ได้ใน 4 บรรทัด — เข้าข่ายโจทย์ “จงแสดงว่า”
กฎข้อ 2 : ΔS_รวม = −Q_H/T_H + Q_C/T_C ≥ 0 ย้ายข้าง : Q_C/T_C ≥ Q_H/T_H จัดรูป : Q_C/Q_H ≥ T_C/T_H คูณ −1 บวก 1 : 1 − Q_C/Q_H ≤ 1 − T_C/T_H η ≤ 1 − T_C/T_H เครื่องหมาย = เกิดเมื่อ ΔS = 0 คือ reversible

η_Carnot = 1 − T_C/T_H ไม่ใช่สูตรที่ต้องท่อง — มันตกมาจากกฎข้อที่สองโดยตรง · ซ้อมเขียน 4 บรรทัดนี้ให้ได้

⑤ ประโยคปิดเขาสับสนระหว่าง “พลังงานสมดุล” กับ “กระบวนการเกิดขึ้นได้จริง” — กฎข้อที่หนึ่งบอกแค่ว่าพลังงานต้องครบ แต่ไม่ได้บอกทิศทาง · การเปลี่ยนความร้อน (พลังงานที่ปั่นป่วนไร้ระเบียบ) ให้เป็นงาน (พลังงานที่เป็นระเบียบ) ได้ 100% หมายถึงการทำลายเอนโทรปี ซึ่งธรรมชาติห้ามไว้
⭐⭐⭐เก็ง 2 · เปิดประตูตู้เย็นทำให้ห้องเย็นลงกฎข้อ 2 · Clausius · COP
โจทย์ที่เก็งในห้องที่ปิดสนิทและหุ้มฉนวนอย่างดี (สถานการณ์เดียวกับ QUIZ-01) เพื่อนคนหนึ่งเสนอว่า “ถ้าอยากให้ห้องเย็น ก็แค่เปิดประตูตู้เย็นทิ้งไว้” จงวิเคราะห์ว่าห้องจะเย็นลง ร้อนขึ้น หรือเท่าเดิม และเขาผิดตรงไหน
ทำไมเก็งข้อนี้สูง

ใช้ฉากเดิมกับ QUIZ-01 เป๊ะ (ห้องปิดหุ้มฉนวน) แต่เปลี่ยนจากกฎข้อ 1 เป็นกฎข้อ 2 — เป็นการต่อยอดที่อาจารย์ทำได้ง่ายที่สุด

① ระบบ = ห้องทั้งห้อง (รวมตู้เย็นเข้าไปด้วย)
หุ้มฉนวน → Q = 0 (ไม่มีความร้อนข้ามผนังห้อง) แต่มีไฟฟ้าเข้ามา → W > 0 (สายไฟเสียบจากนอกห้อง) ΔU = Q + W = 0 + W = W > 0 → ห้องร้อนขึ้น
② ตู้เย็นทำอะไรจริง ๆ
ดูดความร้อน Q_C ออกจากในตู้ ปล่อยความร้อน Q_H ออกที่คอยล์ด้านหลัง Q_H = Q_C + W ← ปล่อยออกมากกว่าดูดเข้าเสมอ ส่วนเกินคือไฟฟ้าที่จ่าย

เมื่อเปิดประตูทิ้งไว้ ทั้ง Q_C และ Q_H อยู่ในห้องเดียวกัน หักกลบแล้วเหลือ +W สุทธิ → ห้องร้อนขึ้นเรื่อย ๆ ตามกำลังไฟที่ตู้เย็นกิน

③ เชื่อมกับกฎข้อที่สอง

Clausius: ความร้อนไม่ไหลจากที่เย็นไปที่ร้อนเองโดยไม่มีงานจากภายนอก → ตู้เย็นทำได้เพราะจ่ายงาน และงานที่จ่ายนั้นสุดท้ายกลายเป็นความร้อนทั้งหมด · ตู้เย็นจึงเป็นเครื่องย้ายความร้อน ไม่ใช่เครื่องทำลายความร้อน

⑤ ประโยคปิดเขาสับสนระหว่าง “ตู้เย็นทำให้ของในตู้เย็นลง” กับ “ตู้เย็นทำให้พลังงานความร้อนหายไป” — ตู้เย็นแค่ย้ายความร้อนจากที่หนึ่งไปอีกที่หนึ่ง และยังเพิ่มความร้อนเข้าไปอีกเท่ากับงานไฟฟ้าที่ใช้ · ห้องปิดหุ้มฉนวนจะร้อนขึ้น ไม่ใช่เย็นลง
⭐⭐⭐เก็ง 3 · Q = 0 แล้วทำไม ΔS ไม่เป็นศูนย์เอนโทรปี · reversible
โจทย์ที่เก็งแก๊สอุดมคติ 1 โมลอยู่ในครึ่งซ้ายของภาชนะหุ้มฉนวน อีกครึ่งเป็นสุญญากาศ เมื่อดึงฉากกั้นออก แก๊สขยายเต็มภาชนะ
นักศึกษาคนหนึ่งตอบว่า “ภาชนะหุ้มฉนวน Q = 0 ดังนั้น ΔS = Q/T = 0 เอนโทรปีไม่เปลี่ยน” จงวิเคราะห์ว่าถูกหรือผิด และเพราะอะไร
ทำไมเก็งข้อนี้สูงมาก

สถานการณ์นี้โผล่ในการบ้านถึง 4 ข้อ (17, 20, 25, 30) — อาจารย์ให้ซ้ำขนาดนี้แปลว่าถือว่าสำคัญมาก

ส่วนที่เขาคิดถูก (ต้องเขียนด้วย จะได้ดูว่าเราเข้าใจ ไม่ได้ค้านมั่ว)
W = 0 ← ไม่มีอะไรให้ดัน (สุญญากาศไม่มีแรงต้าน) Q = 0 ← หุ้มฉนวน ΔU = Q + W = 0 → แก๊สอุดมคติ U ขึ้นกับ T เท่านั้น → T ไม่เปลี่ยน ✓
ส่วนที่เขาคิดผิด — ผิดที่ตัวสูตร ไม่ใช่ผิดที่ตัวเลข
สูตรจริงคือ dS = δQ_rev / T ← มีคำว่า rev ห้อยอยู่

สูตรนี้ใช้ได้เฉพาะกระบวนการผันกลับได้เท่านั้น · การขยายสู่สุญญากาศเป็น irreversible อย่างชัดเจน — แก๊สที่กระจายเต็มภาชนะแล้วไม่มีวันกลับไปกระจุกอยู่ครึ่งซ้ายเองได้ → จึงเอา Q = 0 ไปแทนตรง ๆ ไม่ได้

วิธีที่ถูกต้อง

เพราะ S เป็นฟังก์ชันสถานะ (ขึ้นกับสถานะเท่านั้น ไม่ขึ้นกับเส้นทาง) เราจึงสมมติเส้นทางผันกลับได้ขึ้นมาใหม่ที่เชื่อมสถานะเริ่มต้นกับสถานะสุดท้ายอันเดียวกัน แล้วคำนวณบนเส้นทางสมมตินั้น

เลือกเส้นทางสมมติ : ขยายตัวแบบ isothermal ช้า ๆ (เพราะ T ไม่เปลี่ยนเหมือนกัน) ΔS = n R ln(V_f/V_i) = (1)(8.314) ln 2 = +5.76 J/K > 0 ✓
🎁 ของแถมที่จะทำให้ได้คะแนนเต็ม — ตรวจสอบด้วยนิยามเชิงสถิติ
แต่ละโมเลกุลมีที่ให้อยู่เพิ่มเป็น 2 เท่า → Ω_f / Ω_i = 2^N ΔS = k ln Ω_f − k ln Ω_i = k ln(2^N) = N k ln 2 = n R ln 2 ✓ ตรงกันพอดี

นิยามทั้งสองแบบให้คำตอบเดียวกัน — เขียนอันนี้ลงไปด้วยจะโดดเด่นมาก เพราะแสดงว่าเข้าใจทั้งมุมอุณหพลศาสตร์และมุมสถิติ

⑤ ประโยคปิดเขาสับสนระหว่าง “ความร้อนที่ถ่ายเทจริง (Q = 0)” กับ “ความร้อนบนเส้นทางผันกลับได้สมมติ (Q_rev ≠ 0)” — สูตร dS = δQ/T ไม่ได้ใช้ Q ที่เกิดขึ้นจริง แต่ใช้ Q ของเส้นทางผันกลับได้ที่เชื่อมสองสถานะเดียวกัน
⭐⭐เก็ง 4 · ให้ความร้อนเท่ากัน ทำไมร้อนขึ้นไม่เท่ากันequipartition
โจทย์ที่เก็งถังแข็งสองใบ ใบหนึ่งบรรจุฮีเลียม (He) อีกใบบรรจุไนโตรเจน (N₂) จำนวนโมลเท่ากัน อุณหภูมิเริ่มต้นเท่ากัน ให้ความร้อนเข้าไปเท่ากัน
จงอธิบายว่าอุณหภูมิของแก๊สทั้งสองจะเพิ่มขึ้นเท่ากันหรือไม่ เพราะอะไร
ทำไมเก็งข้อนี้

อาจารย์ทำสไลด์เรื่อง equipartition ให้ถึง 3 หน้าเต็ม (10, 11, 12) มากที่สุดของหัวข้อเดียว และตั้งคำถามไว้เองในสไลด์ 2 ข้อ

คำตอบ: ไม่เท่ากัน — N₂ ร้อนขึ้นน้อยกว่า
He (อะตอมเดี่ยว) วิ่งได้ 3 แกน f = 3 → C_v = 1.5R N₂ (ไดอะตอมิก) วิ่ง 3 แกน + หมุนได้อีก 2 แกน f = 5 → C_v = 2.5R ถังแข็ง → W = 0 → Q = ΔU = n C_v ΔT → ΔT = Q/(n C_v) ΔT(N₂) / ΔT(He) = 1.5R / 2.5R = 3/5 → N₂ ร้อนขึ้นแค่ 60% ของ He
เหตุผลเชิงกายภาพ — นี่คือส่วนที่ได้คะแนน

พลังงานที่ใส่เข้าไปถูกแบ่งเท่า ๆ กันให้ทุกช่องทางที่โมเลกุลเก็บพลังงานได้ ช่องละ ½kT (equipartition) · N₂ มีช่องมากกว่า (หมุนได้ด้วย) พลังงานส่วนหนึ่งจึงไปเก็บในการหมุน ไม่ได้ไปเพิ่มความเร็วเลื่อนตำแหน่งทั้งหมด
และอุณหภูมิวัดเฉพาะพลังงานจลน์เลื่อนตำแหน่ง (½mv̄² = (3/2)kT) → N₂ จึงร้อนขึ้นน้อยกว่าทั้งที่ได้พลังงานเท่ากัน

2 คำถามพ่วงที่อาจารย์เขียนไว้เองในสไลด์ — ต้องตอบได้

Q: ทำไมการสั่นให้ 2 dof ไม่ใช่ 1? → เพราะ E_vib = ½μẋ² + ½kx² มีสองพจน์กำลังสอง (จลน์ + ศักย์ในสปริงพันธะ) ส่วนการวิ่งกับการหมุนมีแค่พจน์จลน์

Q: ทำไม N₂ ที่ T ห้องถึงใช้ f = 5 ไม่ใช่ 7? → โหมดการสั่นถูก “แช่แข็ง” (frozen out) ตามกลศาสตร์ควอนตัม — ระดับพลังงานการสั่นห่างเกินกว่าพลังงานความร้อนที่ T ห้องจะกระตุ้นได้

Q: ทำไม C_p > C_v เสมอ? → ที่ P คงที่ แก๊สต้องขยายตัวดันสิ่งแวดล้อมไปด้วย พลังงานส่วนหนึ่งจึงไปเป็นงาน เหลือไปเพิ่ม T น้อยลง ต้องใส่ความร้อนมากกว่าเพื่อให้ได้ ΔT เท่ากัน · ส่วนต่างพอดีเท่ากับงานขยายตัว: C_p − C_v = R

⭐⭐เก็ง 5 · เดือดแล้วทำไมอุณหภูมิไม่ขึ้นquality x · ความร้อนแฝง
โจทย์ที่เก็งต้มน้ำในหม้อเปิดจนเดือดที่ 100 °C แล้วเร่งไฟให้แรงขึ้น แต่เทอร์โมมิเตอร์ยังค้างที่ 100 °C ไม่ขยับ เพื่อนบอกว่า “เทอร์โมมิเตอร์เสียแน่ ๆ เพราะเราใส่ความร้อนเพิ่มแท้ ๆ”
จงอธิบายว่าเกิดอะไรขึ้น และปริมาณใดที่เปลี่ยนไปจริงในช่วงนี้
เทอร์โมมิเตอร์ไม่ได้เสีย — พลังงานไปที่อื่น

อุณหภูมิวัดพลังงานจลน์เฉลี่ยของโมเลกุล · แต่ในช่วงเดือด พลังงานที่ใส่เข้าไปไม่ได้ไปเพิ่มความเร็วโมเลกุล แต่ไปดึงโมเลกุลออกจากกัน ทำลายแรงยึดเหนี่ยวเพื่อให้หลุดจากของเหลวกลายเป็นไอ → เรียกว่า ความร้อนแฝง (latent = แฝงอยู่ ไม่แสดงออกทางอุณหภูมิ)

Q = m · h_fg h_fg @1 atm = 2256.5 kJ/kg
แล้วอะไรเปลี่ยน — ตัวแปรที่ต้องตอบคือ x
x = m_ไอ / m_รวม เพิ่มจาก 0 → 1 ตลอดช่วงที่เดือด โดยที่ T และ P คงที่ตลอด

ในโดมของผสมอิ่มตัว P กับ T ไม่เป็นอิสระต่อกัน (น้ำเดือดที่ 1 atm ต้องเป็น 100 °C เสมอ) รู้ P ก็รู้ T ทันที ไม่ได้ข้อมูลใหม่ → จึงต้องมีตัวแปรที่สาม คือ x มาบอกว่ากระบวนการเดินไปถึงไหนแล้ว
เร่งไฟแรงขึ้น = x เพิ่มเร็วขึ้น = น้ำแห้งเร็วขึ้น ไม่ใช่ร้อนขึ้น

⑤ ประโยคปิดเขาสับสนระหว่าง “ใส่พลังงานเข้าไป” กับ “อุณหภูมิต้องเพิ่ม” — พลังงานที่ใส่เข้าไปเปลี่ยนสถานะของสสาร (ของเหลว → ไอ) ไม่ได้เปลี่ยนความเร็วของโมเลกุล และอุณหภูมิวัดเฉพาะอย่างหลัง
⭐เก็ง 6 · ทำไมเทอร์โมมิเตอร์ถึงเชื่อถือได้กฎข้อ 0
โจทย์ที่เก็งเราเอาเทอร์โมมิเตอร์จุ่มกาแฟอ่านได้ 60 °C แล้วเอาไปจุ่มซุปอ่านได้ 60 °C เท่ากัน เราสรุปว่ากาแฟกับซุปมีอุณหภูมิเท่ากัน
ทั้งที่เราไม่เคยเอากาแฟไปแตะซุปเลยสักครั้ง จงอธิบายว่าอะไรทำให้การสรุปแบบนี้ถูกต้องทางฟิสิกส์
คำตอบ: กฎข้อที่ศูนย์
ถ้า A สมดุลความร้อนกับ C และ B สมดุลความร้อนกับ C แล้ว A ต้องสมดุลความร้อนกับ B ด้วย (A = กาแฟ · B = ซุป · C = เทอร์โมมิเตอร์)

สมบัติ “ถ่ายทอดได้” (transitive) นี้ไม่ใช่เรื่องที่พิสูจน์ได้จากกฎอื่น แต่เป็นข้อเท็จจริงที่สังเกตได้จากธรรมชาติ จึงต้องยกเป็น “กฎ”

ทำไมมันสำคัญพอที่จะเป็น “กฎ”

ถ้าธรรมชาติไม่มีสมบัตินี้ เทอร์โมมิเตอร์จะใช้ไม่ได้เลย — เราจะต้องเอาของทุกคู่มาแตะกันเองเพื่อเทียบ ซึ่งเป็นไปไม่ได้ในทางปฏิบัติ · กฎข้อนี้คือสิ่งที่ทำให้ “อุณหภูมิ” เป็นปริมาณที่มีความหมายและวัดได้
และเพราะกฎอื่น ๆ ทั้งหมดใช้ตัวแปร T กฎข้อนี้จึงต้องมาก่อน → ถูกตั้งชื่อว่า “ข้อที่ศูนย์” ทั้งที่ถูกค้นพบทีหลัง

ถ้าอยากได้คะแนนเต็ม เติมนิยามเข้ม
1/T = (∂S/∂U)_{V,N}

อุณหภูมิที่นิยามอย่างเข้มงวดคืออนุพันธ์ของเอนโทรปีเทียบพลังงาน ไม่ใช่ “พลังงานจลน์เฉลี่ย” — คำกล่าวว่า T = พลังงานจลน์เฉลี่ยนั้นถูกเฉพาะกับการเคลื่อนที่เลื่อนตำแหน่งของแก๊สอุดมคติเท่านั้น

⭐เก็ง 7 · ทำไมกระบวนการจริงไม่มีทาง reversiblereversible · irreversible
โจทย์ที่เก็งจงอธิบายความหมายของกระบวนการ ผันกลับได้ (reversible) · ยกตัวอย่างกระบวนการที่ผันกลับไม่ได้มาอย่างน้อย 3 ตัวอย่างพร้อมเหตุผล · และอธิบายว่าทำไมกระบวนการผันกลับได้จึงให้งานสูงสุด ทั้งที่ในความเป็นจริงไม่มีทางทำได้
นิยาม

Reversible: กระบวนการที่ระบบผ่านสภาวะสมดุลตลอดเวลา และสามารถย้อนกลับสู่สถานะเดิมได้โดยไม่ทิ้งร่องรอยใด ๆ ทั้งในระบบและสิ่งแวดล้อม · ΔS_รวม = 0
Irreversible: ทุกกระบวนการที่เกิดขึ้นจริงในธรรมชาติ · ΔS_รวม > 0

ตัวอย่าง irreversible + เหตุผล
① แรงเสียดทาน งานกลกลายเป็นความร้อน แต่ความร้อนไม่กลับมา เป็นงานกลเองได้ (นี่คือกรณีใน QUIZ-01) ② ถ่ายเทความร้อน ความร้อนไหลจากร้อนไปเย็นเอง แต่ไม่ไหลย้อนเอง ผ่านผลต่าง T ที่มีขนาดจำกัด ③ ขยายสู่สุญญากาศ แก๊สกระจายเต็มภาชนะเอง แต่ไม่กระจุกกลับเอง ④ การกวนด้วยใบพัด งานกลกลายเป็นความร้อนในของเหลว ย้อนไม่ได้
ทำไม reversible ให้งานสูงสุด

ทุกความ irreversible (เสียดทาน ผลต่างอุณหภูมิ ความปั่นป่วน) สร้างเอนโทรปีขึ้นมาใหม่ และเอนโทรปีที่สร้างขึ้นนั้นแลกมาด้วยพลังงานที่เสื่อมคุณภาพจากงานที่เป็นระเบียบ กลายเป็นความร้อนที่ไร้ระเบียบ ซึ่งดึงกลับมาใช้ได้ไม่หมด
→ กระบวนการที่ ไม่สร้างเอนโทรปีเลย (reversible) จึงไม่มีการสูญเสียส่วนนี้ = ได้งานออกมามากที่สุดที่เป็นไปได้

ประโยคปิดreversible เป็นอุดมคติที่ใช้เป็นขีดจำกัดเปรียบเทียบ ไม่ใช่สิ่งที่สร้างได้จริง — เหมือนวัฏจักรคาร์โนต์ที่บอกเราว่า “ดีที่สุดเท่าที่ธรรมชาติอนุญาต” คือเท่าไหร่ เพื่อให้รู้ว่าเครื่องยนต์จริงยังห่างจากเพดานแค่ไหน
