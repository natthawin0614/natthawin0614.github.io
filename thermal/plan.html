ขยายสู่สุญญากาศ → W = 0 (เพราะไม่มีอะไรให้ดัน ไม่ใช่เพราะ V คงที่) + หุ้มฉนวน → Q = 0 → ΔU = 0 → แก๊สอุดมคติ : T ไม่เปลี่ยน แต่ ΔS > 0 !! ← ตรงนี้แหละคือข้อสอบ

เพราะเป็นกระบวนการ irreversible จะเอา Q = 0 ไปแทนใน dS = δQ/T ตรง ๆ ไม่ได้ ต้องสมมติเส้นทาง reversible ที่เชื่อมสถานะเริ่มต้นกับสถานะสุดท้ายอันเดียวกัน แล้วคำนวณบนเส้นทางสมมตินั้นแทน (สไลด์ Entropy หน้า 4 พูดเรื่องนี้ตรง ๆ · หน้า 13 อาจารย์เขียนลายมือกำกับว่า free expansion → W = 0, ΔU = 0)
