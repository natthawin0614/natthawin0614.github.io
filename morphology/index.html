Erosion / Dilation / Skeletonization

โปรแกรมช่วยคำนวณและตรวจคำตอบวิชา Computer Vision — วาดวัตถุลงตารางเอง หรืออัปโหลดภาพโจทย์แล้วให้ OpenCV อ่านตารางให้อัตโนมัติ

เป็นโปรแกรมที่ต้องรันบนเครื่องตัวเอง ไม่ได้รันในเว็บ

เขียนด้วย Python + Tkinter ต้องโหลดไฟล์ไปรันในคอมพิวเตอร์ ทำตาม 3 ขั้นตอนข้างล่างได้เลย

1) ติดตั้ง Python

โหลดจาก python.org เวอร์ชัน 3.8 ขึ้นไป ตอนติดตั้งให้ติ๊ก “Add Python to PATH” ด้วย

2) โหลดไฟล์

คลิกขวาที่แต่ละไฟล์แล้วเลือก “Save link as…” เก็บไว้ในโฟลเดอร์เดียวกันทั้งหมด

  • morph_skel.pyโปรแกรมหลัก — ไฟล์ที่ใช้รัน
  • grid_reader.pyตรรกะ OpenCV อ่านตารางจากภาพ
  • image_import.pyหน้าต่างอัปโหลดภาพ
  • requirements.txtรายชื่อไลบรารี
  • test_all.pyชุดทดสอบ (ไม่บังคับ)
  • test_grid.pngภาพตัวอย่างไว้ลองอ่านภาพ

3) เปิดโปรแกรม

เปิด Command Prompt ในโฟลเดอร์นั้น แล้วพิมพ์

pip install -r requirements.txt
python morph_skel.py
ถ้าไม่อยากติดตั้งอะไรเพิ่ม ข้ามบรรทัด pip install ได้เลย โปรแกรมยังใช้ได้ปกติ เพียงแต่ปุ่ม “อ่านตารางจากภาพ” จะใช้ไม่ได้

ทำอะไรได้บ้าง

  • เลือก Structuring Element — ป็อปอัพตาราง 3×3 คลิกเลือกช่องที่เป็นสีดำ
  • วาดวัตถุลงตาราง 13 × 10 — คลิกซ้ายระบายดำ คลิกขวาลบ ปรับขนาดตารางได้
  • Erosion, Dilation, Opening, Closing — แสดงขั้นกลางให้เห็นด้วย
  • Skeletonization — Pass one / Pass two / ทั้งสอง / วนจนได้เส้นกระดูก พร้อมจุดแดงบอกว่ารอบนั้นลบจุดไหน
  • อ่านตารางจากภาพ — อัปโหลดภาพถ่ายหรือภาพสแกน แล้วระบายสีให้อัตโนมัติ
  • คัดลอกเป็นโค้ด MATLAB — เอาไปวางตรวจคำตอบต่อได้

สูตรที่ใช้

Erosion ผลเป็น 1 เมื่อจุดที่เป็น 1 ของ SE ชนกับวัตถุทุกจุด
Dilation ผลเป็น 1 เมื่อจุดที่เป็น 1 ของ SE ชนกับวัตถุอย่างน้อยหนึ่งจุด

ถ้า SE มีจุดกึ่งกลางเป็น 0 เช่น [0 1 0; 1 0 0; 0 1 0] ในแบบฝึกหัด ผล Erosion จะ งอกจุดใหม่นอกรูปเดิมได้ เพราะการตัดสินแต่ละช่องไม่ได้ดูตัวช่องนั้นเลย กฎ “Erosion ต้องเล็กลงเสมอ” ใช้ได้เฉพาะตอน SE มีจุดกึ่งกลางเป็น 1 ผลตรงกับ imerode ของ MATLAB และ scipy

Skeletonization ใช้ Zhang-Suen ตามสไลด์ เลขเพื่อนบ้านเรียงตามเข็มนาฬิกา

เงื่อนไขข้อ 3 คือ “ถ้าสามจุดด้านใดด้านหนึ่งเป็น foreground หมด จะลบจุดนั้นไม่ได้”
