# Erosion / Dilation / Skeletonization

โปรแกรมช่วยคำนวณและตรวจคำตอบวิชา Computer Vision เรื่อง **Dilation, Erosion และ Skeletonization**
วาดวัตถุลงตารางด้วยเมาส์ หรืออัปโหลดภาพโจทย์แล้วให้ OpenCV อ่านตารางให้อัตโนมัติ

## ความสามารถ

**ส่วนที่ 1 — เลือก Structuring Element**
ป็อปอัพตาราง 3×3 คลิกเมาส์เลือกช่องที่เป็นสีดำ มีรูปแบบสำเร็จรูปให้เลือก
กรอบสีแดงคือจุดกึ่งกลาง (origin)

**ส่วนที่ 2 — วาดวัตถุลงตาราง 13 × 10**
คลิกซ้ายระบายดำ คลิกขวาลบ พร้อมเลขแกนและเส้นแบ่งจุดไข่ปลาแบบเดียวกับในแบบฝึกหัด
ปรับขนาดตารางเป็นขนาดอื่นได้ เช่น 8×8

**การคำนวณ**

| กลุ่ม | รายการ |
| --- | --- |
| Morphology | Erosion, Dilation, Opening (Erosion → Dilation), Closing (Dilation → Erosion) |
| Skeletonization | Pass one, Pass two, Pass one + Pass two, คำนวณเต็มจนได้เส้นกระดูก |

แสดงผลเป็น 3 ตาราง (ต้นฉบับ → ขั้นกลาง → ผลลัพธ์) เห็นขั้นตอนกลางของ Opening/Closing
และตอนทำ Pass จะมีจุดสีแดงบอกว่ารอบนั้นลบจุดไหนไปบ้าง พร้อมพิมพ์เมทริกซ์ 0/1 ให้คัดลอก

**อ่านตารางจากภาพด้วย OpenCV**
อัปโหลดภาพโจทย์ (ถ่ายจากมือถือหรือสแกน) แล้วโปรแกรมจะจับเส้นตาราง นับจำนวนแถว/หลัก
และระบายสีให้อัตโนมัติ รองรับภาพเอียง ภาพถ่ายมุมเอียง เงา และ JPEG คุณภาพต่ำ

## สูตรที่ใช้

**Erosion** ผลเป็น 1 เมื่อจุดที่เป็น 1 ของ SE ชนกับวัตถุ**ทุกจุด**
**Dilation** ผลเป็น 1 เมื่อจุดที่เป็น 1 ของ SE ชนกับวัตถุ**อย่างน้อยหนึ่งจุด**

> **ข้อควรระวัง** ถ้า SE มีจุดกึ่งกลางเป็น 0 (เช่น `[0 1 0; 1 0 0; 0 1 0]` ในแบบฝึกหัด)
> ผล Erosion จะ**งอกจุดใหม่นอกรูปเดิมได้** เพราะการตัดสินแต่ละช่องไม่ได้ดูตัวช่องนั้นเลย
> กฎ "Erosion ต้องเล็กลงเสมอ" ใช้ได้เฉพาะตอน SE มีจุดกึ่งกลางเป็น 1
> โปรแกรมจะขึ้นหมายเหตุบอกเมื่อเจอกรณีนี้ ผลตรงกับ `imerode` ของ MATLAB และ `scipy`

**Skeletonization** ใช้ Zhang-Suen ตามสไลด์ เลขเพื่อนบ้านเรียงตามเข็มนาฬิกา

```
8 1 2
7 P 3
6 5 4
```

| | Pass one | Pass two |
| --- | --- | --- |
| 1) | 8-Connected 2 ถึง 6 | 8-Connected 2 ถึง 6 |
| 2) | Crossing index = 1 | Crossing index = 1 |
| 3) | `n3·n5·n7 = 0` และ `n1·n3·n5 = 0` | `n1·n5·n7 = 0` และ `n1·n3·n7 = 0` |

เงื่อนไขข้อ 3 คือ "ถ้าสามจุดด้านใดด้านหนึ่งเป็น foreground หมด จะลบจุดนั้นไม่ได้"

## ตรวจกับ MATLAB

ปุ่ม **คัดลอกเป็นโค้ด MATLAB** จะคัดลอกคำสั่งไปที่คลิปบอร์ดให้เอาไปวางตรวจคำตอบได้เลย

```matlab
p1_bw = imbinarize(p1);
p1_er = imerode(p1_bw, se);
p1_di = imdilate(p1_bw, se);
```

> `imdilate` ของ MATLAB **สะท้อน SE ก่อน** ถ้า SE ไม่สมมาตรผลจะต่างจากนิยามในสไลด์
> ให้ติ๊ก "สะท้อน SE ตอน Dilation" ในโปรแกรมเพื่อเทียบกับ MATLAB
> ส่วน Erosion ทั้งสองนิยามตรงกันอยู่แล้ว
