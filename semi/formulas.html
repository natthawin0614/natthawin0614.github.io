🌳 ผังตัดสินใจ — โจทย์แบบไหนใช้สูตรไหน

❓ โจทย์ให้ NA, ND, ni → ถามหา n, p

โดปตัวเดียว และ N ≫ n_i ? ├─ ใช่ → n-type: n = N_D , p = n_i²/N_D │ p-type: p = N_A , n = n_i²/N_A └─ ไม่ (โดปทั้งสอง) → หา net doping ก่อน N_D − N_A > 0 → n ≈ N_D − N_A, แล้ว p = n_i²/n N_A − N_D > 0 → p ≈ N_A − N_D, แล้ว n = n_i²/p ⚠️ ถ้า net doping ใกล้เคียง n_i → ต้องใช้สมการกำลังสองเต็มรูป ⚠️ ถ้าโจทย์ให้ T = 0 K → dopant ยังไม่ ionize → n = p = 0 (freeze-out!)

❓ ถามหาตำแหน่ง EF

โจทย์ให้ n_i และ n (หรือ p) ? └─ ใช้ E_F − E_i = k_BT·ln(n/n_i) = −k_BT·ln(p/n_i) ← ง่ายสุด ใช้อันนี้ โจทย์ให้ m*, E_g และเป็น intrinsic ? └─ ใช้ E_F = E_g/2 + (3/4)k_BT·ln(m*ₚ/m*ₙ) (วัดจาก E_v = 0) โจทย์ให้ N_c หรือ m* และให้ E_c−E_F ? └─ ใช้ n = N_c·exp[−(E_c−E_F)/k_BT]

❓ ถามเรื่องกระแส/ความต้านทาน

ให้ E field และ n,p,μ → J = q(nμₙ + pμₚ)E หรือ σ = q(nμₙ+pμₚ) ให้ profile ความเข้มข้น → J_diff: J_P = −qD_p dp/dx , J_N = +qD_n dn/dx ให้ μ แต่ต้องการ D → D = μ·(k_BT/q) = μ × 0.026 ให้ ρ และ J → E = J·ρ (Ohm) ให้ V และความยาว L → E = V/L มี E field แล้วอยากได้ v → v_d = μE

❓ โจทย์ pn junction

ขั้นที่ 1 เสมอ → V_bi = (k_BT/q)·ln(N_A N_D / n_i²) [เช็ก: ต้อง < E_g/q] ขั้นที่ 2 → x_n, x_p ตามสูตร (จำ: ฝั่ง n ใช้ N_A บนเศษ) ขั้นที่ 3 → W = x_n + x_p ขั้นที่ 4 → E_max = −qN_A x_p/(ε_rε₀) = −qN_D x_n/(ε_rε₀) ถ้าโจทย์ให้ band diagram มาแทน: → qV_bi = (E_i−E_F)_p-side + (E_F−E_i)_n-side

📋 สูตรทั้งหมด เรียงตามบท

บท 1 พื้นฐาน

E_g = E_c − E_v สมการการเคลื่อนที่: ในที่ว่าง : F = −qE = m₀ dv/dt e⁻ ในผลึก : F = −qE = m*ₙ dv/dt hole : F = +qE = m*ₚ dv/dt พลังงาน ionization ของไฮโดรเจน : m e⁴ / (8ε₀²h²) = 13.6 eV พลังงาน ionization ของ donor ใน Si: m*ₙ e⁴ / (8(ε_rε₀)²h²) ≈ 0.1 eV

บท 2 สถิติพาหะ

g_c(E) = (1/π²ℏ³)√(2m*ₙ³)·√(E−E_c) g_v(E) = (1/π²ℏ³)√(2m*ₚ³)·√(E_v−E) f(E,T) = 1/[exp((E−E_F)/k_BT) + 1] · f(E_F)=0.5 · P(ว่าง)=1−f(E) เงื่อนไข non-degenerate: E − E_F > 3.5 k_BT n = N_c·exp[−(E_c−E_F)/k_BT] , N_c = 2[2π m*ₙ k_BT / h²]^(3/2) p = N_v·exp[−(E_F−E_v)/k_BT] , N_v = 2[2π m*ₚ k_BT / h²]^(3/2) E_F(intrinsic) = E_g/2 + (3/4)k_BT·ln(m*ₚ/m*ₙ) [E_v = 0] np = n_i² = N_c N_v exp(−E_g/k_BT) ⇒ n_i = √(N_c N_v)·exp(−E_g/2k_BT) สมดุลประจุ: p − n + N_D⁺ − N_A⁻ = 0 (หรือ n + N_A⁻ = p + N_D⁺) n = (N_D−N_A)/2 + √[ ((N_D−N_A)/2)² + n_i² ] p = (N_A−N_D)/2 + √[ ((N_A−N_D)/2)² + n_i² ] n = n_i·exp[(E_F−E_i)/k_BT] p = n_i·exp[(E_i−E_F)/k_BT] E_F − E_i = k_BT·ln(n/n_i) = −k_BT·ln(p/n_i) ΔPE_p = +qV ΔPE_n = −qV E = −dV/dx = (1/q)dE_c/dx = (1/q)dE_v/dx = (1/q)dE_i/dx

บท 3 Drift & Diffusion

v_d,p = +(qτ/m*ₚ)E = +μₚE v_d,n = −(qτ/m*ₙ)E = −μₙE μₚ = qτ/m*ₚ μₙ = qτ/m*ₙ 1/τ_l ∝ T^(+3/2) [lattice] 1/τ_ii ∝ T^(−3/2) [ionized dopant] 1/τ = 1/τ_l + 1/τ_ii J_P|drift = q p μₚ E J_N|drift = q n μₙ E J = σE = E/ρ σ = q(nμₙ + pμₚ) ρ = 1/[q(nμₙ + pμₚ)] n-type: ρ = 1/(qμₙN_D) p-type: ρ = 1/(qμₚN_A) Fick: F = −D∇η J_P|diff = −q D_p (dp/dx) J_N|diff = +q D_n (dn/dx) J_P = q p μₚE − q D_p dp/dx J_N = q n μₙE + q D_n dn/dx ที่สมดุล: J_P|drift = −J_P|diff และ J_N|drift = −J_N|diff Einstein: D_n/μₙ = D_p/μₚ = k_BT/q = 0.026 V @300K

บท 4 R–G (ไม่มีสูตรคำนวณ)

Band-to-band : โฟตอนพลังงาน = E_g (radiative) R–G center : คายเป็นความร้อน (NON-radiative) · ระดับใกล้กลาง gap · Fe,Cr,Mn,Cu,Au Auger : R เท่านั้น · เกิดที่ โดปหนัก Impact ioniz. : G เท่านั้น · เกิดที่ สนามสูง · = inverse ของ Auger · ทำให้เกิด avalanche breakdown Direct (GaAs,GaN): CB min กับ VB max อยู่ k เดียวกัน → เปล่งแสงได้ดี → LED/LASER Indirect (Si,Ge) : อยู่คนละ k → ต้องใช้ โฟตอน + โฟนอน พร้อมกัน → เปล่งแสงแย่ โฟตอน: E สูง p ต่ำ | โฟนอน: E ต่ำ p สูง

บท 5 pn Junction

qV_bi = (E_i−E_F)_p-side + (E_F−E_i)_n-side = k_BT·ln(N_A/n_i) + k_BT·ln(N_D/n_i) ⭐ V_bi = (k_BT/q)·ln( N_A N_D / n_i² ) [ต้อง < E_g/q เสมอ] ρ(x) = −qN_A (−x_p<x<0) ; +qN_D (0<x<x_n) ; 0 นอกนั้น Poisson: dE/dx = ρ(x)/(ε_rε₀) E(x) = −(qN_A/ε_rε₀)(x+x_p) (−x_p<x<0) E(x) = −(qN_D/ε_rε₀)(x_n−x) (0<x<x_n) ⭐ E_max = E(0) = −(qN_A/ε_rε₀)x_p = −(qN_D/ε_rε₀)x_n ⭐ N_A x_p = N_D x_n (สมดุลประจุ / Gauss's law) V_bi = (q/2ε_rε₀)(N_A x_p² + N_D x_n²) [= พื้นที่ใต้กราฟ E(x)] ⭐ x_n = [ (2ε_rε₀/q) · N_A/(N_D(N_A+N_D)) · V_bi ]^0.5 ⭐ x_p = [ (2ε_rε₀/q) · N_D/(N_A(N_A+N_D)) · V_bi ]^0.5 ⭐ W = x_n + x_p = [ (2ε_rε₀/q) · (N_A+N_D)/(N_A N_D) · V_bi ]^0.5

#กับดักวิธีกันพลาด
1หน่วย cm vs m — ค่าตารางเป็น cm แต่ค่าคงที่บางตัวเป็น SIตัดสินใจตั้งแต่ต้นว่าจะทำระบบไหน แล้วแปลงให้หมด · จำ 1 cm⁻³ = 10⁶ m⁻³
2xn กับ xp ใช้ N สลับกันท่อง "ฝั่งไหน ใช้โดปของอีกฝั่ง" · เช็กด้วยสามัญสำนึก: โดปหนัก = depletion บาง
3ลืมว่า P, As, Sb เป็น donor ทั้งหมด (ต้องบวกกัน)ท่อง: หมู่ III = B, Al, Ga, In = acceptor · หมู่ V = P, As, Sb = donor
4ใช้ μ ค่าเดิมทั้งที่โดปหนักขึ้นถ้าโจทย์ให้ μ ใหม่มา = ต้องใช้ค่าใหม่ (ionized impurity scattering)
5เครื่องหมาย Jdiff ของ e⁻ กับ holehole = −qDpdp/dx (มีลบ) · electron = +qDndn/dx (ไม่มีลบ)
6คิดว่ากระแส e⁻ กับ hole หักล้างกันไม่! ประจุลบ × วิ่งสวน = บวก ⇒ บวกกัน
7โจทย์ T = 0 K แล้วยังตอบ n = NDที่ 0 K ไม่มี ionization → n = p = 0 (freeze-out)
8Vbi ออกมามากกว่า Eg/qผิดแน่นอน — เช็ก ni ว่ายกกำลัง 2 หรือยัง
9วาดกราฟไม่กลับด้าน ตอนโจทย์วาง n ไว้ซ้ายอ่านรูปในโจทย์ให้ดีก่อนวาด (HW2 ข้อ 5 หลอกตรงนี้)
10ใช้สูตรบท 2 กับสาร degenerateเช็ก EF ว่ายังอยู่ใน gap ห่างขอบ > 3.5kBT ไหม
11คำนวณ Eg/2 แล้วลืมว่า Ev=0ระบุจุดอ้างอิงพลังงานให้ชัดทุกครั้งที่วาด band diagram
12ลืม √ ในสูตร xn, xp, Wเลขชี้กำลัง 0.5 อยู่นอกวงเล็บใหญ่ — กดเครื่องคิดเลขให้ครบ

🧮 เทคนิคเครื่องคิดเลขที่ประหยัดเวลา

  • ln ของเลขยกกำลัง 10: ln(10^N) = 2.3026 × N
    เช่น ln(10¹⁰)=23.03 · ln(10²⁰)=46.05 · ln(4×10¹⁴) = ln4 + 14×2.3026 = 1.386+32.24 = 33.62
  • Vbi สำหรับ Si: Vbi = 0.026 × [ln(NA) + ln(ND) − 2ln(ni)] — แยกกันคิดจะพลาดน้อยกว่า
  • D = μ × 0.026 — ท่องไว้เลย ไม่ต้องคิดใหม่ทุกครั้ง
  • เช็ก order of magnitude ก่อนเสมอ: เช่น ND=10¹⁷, ni=10¹⁰ ⇒ p ต้อง = 10²⁰/10¹⁷ = 10³ (ไม่ใช่ 10⁷!)
  • เลขยกกำลัง 1.5 (^3/2): กด x^y ด้วย 1.5 ไปเลย · หรือ (√x)³
