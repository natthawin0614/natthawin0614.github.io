Lecture 05 รอยต่อ pn (pn Junction)

อุปกรณ์จริงชิ้นแรก · Built-in voltage · Depletion approximation · Poisson · E(x), V(x), xn, xp, W
🔴 สรุปรุ่นพี่ไม่มีบทนี้เลย · สไลด์ 22 หน้า · บทที่ยากที่สุดและออกอัตนัยแน่นอน

🎯 บทนี้คือจุดที่ทุกอย่างมาบรรจบ บท 1 (โดป) + บท 2 (EF, band bending) + บท 3 (drift & diffusion) → รวมกันเป็นอุปกรณ์ 2 ขั้วชิ้นแรก
ถ้าเข้าใจบทนี้ = เข้าใจ diode, ซึ่งเป็นฐานของ BJT และ MOSFET ทั้งหมด

⭐ สตอรี่ 5 ก้าว — อ่านตรงนี้ก่อนอย่างอื่น

1
เอา p กับ n มาแตะกัน
ฝั่ง p มีโฮลเยอะมาก · ฝั่ง n มีอิเล็กตรอนเยอะมาก → เกิด ความชันความเข้มข้นมหาศาล ที่รอยต่อ
→ บท 3 บอกว่าความชันความเข้มข้น = เกิด diffusion
2
เกิด Depletion Region
โฮลแพร่ไปฝั่ง n · อิเล็กตรอนแพร่ไปฝั่ง p → พอข้ามไปก็ไปรวมตัวกับพาหะข้างมากอีกฝั่งอย่างรวดเร็ว
เหลือทิ้งไว้แต่ ไอออนที่เคลื่อนที่ไม่ได้ (immobile ionized dopants)
→ ฝั่ง p เหลือ ไอออน acceptor ประจุลบ · ฝั่ง n เหลือ ไอออน donor ประจุบวก
บริเวณที่ไม่มีพาหะเคลื่อนที่เหลืออยู่นี้ = depletion region หรือ space charge region
3
เกิดสนามไฟฟ้าในตัว (built-in E field)
ประจุที่ถูกทิ้งไว้สร้างสนามไฟฟ้า — เส้นแรงเริ่มจากประจุบวก (ฝั่ง n) ไปจบที่ประจุลบ (ฝั่ง p)
→ สนามนี้ทำให้เกิด drift ที่สวนทางกับ diffusion พอดี
→ จนถึงจุดที่ drift = −diffusion เป๊ะ ⇒ กระแสสุทธิ = 0 ⇒ สมดุลความร้อน
→ นี่คือข้อสรุป "VERY INTERESTING" ของบท 3 ที่เป็นจริงขึ้นมา!
4
สนามนั้นมาพร้อมกับ Vbi และ band bending
มีสนาม ⇒ มีความต่างศักย์ ⇒ แถบพลังงานโค้งงอ (บท 2)
หา Vbi ได้จากเงื่อนไขทองคำ: ที่สมดุล EF ต้องเป็นเส้นตรงเดียวตลอด junction
→ ได้ Vbi = (kBT/q)·ln(NAND/ni²)
5
แก้อิเล็กโทรสแตติกส์ด้วย Poisson
ใช้ depletion approximation (สมมติว่าในโซนนี้มีแต่ไอออน ไม่มีพาหะเลย) → ได้ ρ(x) เป็นกล่องสี่เหลี่ยม 2 อัน
อินทิเกรต 1 ครั้ง → E(x) รูปสามเหลี่ยม · อินทิเกรตอีกครั้ง → V(x) รูปพาราโบลา
→ ได้สูตร xn, xp, W

5.1 pn junction คืออะไร / สร้างยังไง

  • อุปกรณ์ 2 ขั้ว (two-terminal) เกิดจากการนำสาร n-type มาสัมผัสกับ p-type
  • วิธีสร้างจริง: แพร่ (diffuse) สารเจือลงบนซับสเตรตที่โดปไว้แล้ว
    เช่น ซับสเตรตโดป donor สม่ำเสมอ (n-type) → แพร่ acceptor ลงจากผิว → ผิวหน้ากลายเป็น p-type แต่ข้างล่างยังเป็น n-type
🔑 2 คำศัพท์ที่ต้องรู้ ① Metallurgical junction = จุดที่ net doping = 0 (คือจุดที่ ND − NA = 0)
   สิ่งที่สำคัญในการวิเคราะห์ไม่ใช่ NA หรือ ND เดี่ยว ๆ แต่คือ net doping (ND−NA)
② Abrupt approximation = สมมติว่าโปรไฟล์การโดปเปลี่ยน ทันทีทันใด ที่รอยต่อ (เป็นขั้นบันได)
   ของจริงเปลี่ยนแบบค่อยเป็นค่อยไป แต่สมมติแบบนี้ทำให้คำนวณได้ และแม่นพอ

5.2 Built-in Voltage Vbi ⭐⭐⭐

เข้าใจเชิงคุณภาพก่อน — วาดแผนภาพแถบ

วิธีวาด (ทำตาม 3 ขั้นนี้ทุกครั้ง):

  1. วาดแถบของ p-type และ n-type แยกกันก่อน (EF อยู่ใกล้ Ev ฝั่ง p, ใกล้ Ec ฝั่ง n)
  2. เอามาต่อกัน โดยบังคับให้ EF เป็นเส้นเดียวกันตลอด (เพราะสมดุล)
  3. ลากแถบให้เชื่อมกันอย่างนุ่มนวลผ่าน depletion region → เกิด band bending ขึ้นเอง
แผนภาพแถบของ pn junction ที่สมดุล · แถบฝั่ง p อยู่สูงกว่าฝั่ง n เป็นระยะ qVbi
ไกลจาก depletion region → แถบกลับมาแบนเหมือนสารเดี่ยว ๆ
🔑 อ่านแผนภาพนี้ให้เป็น (ออกสอบชัวร์)
  • EF แบนตลอด ⇒ ระบบอยู่ใน สมดุลความร้อน (ถ้าไม่แบน = ไม่สมดุล มีกระแสไหล)
  • ฝั่ง n มีศักย์ไฟฟ้าสูงกว่า เพราะ depletion ฝั่งนั้นมีประจุบวกสุทธิ
  • ศักย์สูง ⇒ PE ของโฮลสูง ⇒ โฮลฝั่ง n อยู่ "ยอดเนิน" (บท 2) และสลับกันสำหรับอิเล็กตรอน
  • ทั้ง e⁻ และ hole ต่างเห็น กำแพงพลังงาน (energy barrier) ที่กันไม่ให้แพร่ข้ามไปได้อีก
  • Eg คงที่ตลอด — Ec กับ Ev โค้งขนานกันเสมอ (ห้ามวาดให้ gap เปลี่ยน!)

คำนวณ Vbi — ที่มา

นิยาม (สมการ 5.1, 5.2) — วัดจากฝั่ง p ไปฝั่ง n q·V_bi = [E_i − E_F]_ฝั่ง p + [E_F − E_i]_ฝั่ง n ใช้สูตรจากบท 2 (สมการ 2.23/2.24) โดยที่ไกลจาก depletion: p ≈ N_A, n ≈ N_D [E_i − E_F]_ฝั่ง p = k_B T · ln( N_A / n_i ) ...(5.3) [E_F − E_i]_ฝั่ง n = k_B T · ln( N_D / n_i ) ...(5.4) บวกกัน (ln a + ln b = ln ab) ⭐⭐ V_bi = (k_B T / q) · ln( N_A · N_D / n_i² ) ...(5.5)
🔑 3 ข้อสังเกตที่อาจารย์เน้น (คำถาม concept)
  • Vbi ขึ้นกับทั้งอุณหภูมิ และ ความเข้มข้นการโดป
  • T ลด ⇒ Vbi ลด — เพราะพลังงานความร้อนที่ขับ diffusion น้อยลง จึงต้องใช้สนามน้อยลงในการหยุดมัน
  • โดป → 0 ⇒ Vbi → 0 — เพราะกลายเป็นชิ้นสาร intrinsic ชิ้นเดียว ไม่มีรอยต่อ
⚠️ ขีดจำกัดที่ออกสอบบ่อยมาก Vbi ต้องน้อยกว่า Eg/q เสมอ (สำหรับ junction ที่โดปแบบ non-degenerate)
เพราะแถบเลื่อนได้มากสุดคือจนกว่า EF ฝั่งหนึ่งจะแตะ Ec และอีกฝั่งแตะ Ev
วัสดุEgขีดจำกัด Vbi
Si1.12 eVVbi < 1.12 V
Ge0.66 eVVbi < 0.66 V
GaAs1.42 eVVbi < 1.42 V
→ ถ้าคำนวณได้เกินนี้ = ทำผิดแน่นอน ให้เช็กใหม่!

📝 ตัวอย่างจากสไลด์

Si @300K · NA = ND = 10¹⁵ cm⁻³ · ni=10¹⁰ · หา Vbi

V_bi = 0.026 × ln( (10¹⁵ × 10¹⁵) / (10¹⁰)² ) = 0.026 × ln( 10³⁰ / 10²⁰ ) = 0.026 × ln(10¹⁰) = 0.026 × 23.03 = 0.60 V ✓ น้อยกว่า 1.12 V — สมเหตุสมผล

💡 เทคนิคกดเครื่องคิดเลข: ln(10^N) = N × 2.3026 → คิดในใจได้เร็วมาก

5.3 Depletion Approximation

🔑 สมมติฐาน ในความจริง depletion region มีทั้งไอออนและพาหะอิสระบางส่วน
แต่เราสมมติว่า ความเข้มข้นของ e⁻ และ hole ในนั้นน้อยจนละเลยได้ เมื่อเทียบกับความหนาแน่นการโดป
⇒ ใน depletion region มีแต่ ไอออนของสารเจือที่เคลื่อนที่ไม่ได้ เท่านั้น

เหตุผลที่สมมติแบบนี้ได้: จากแผนภาพแถบ — พาหะที่อุณหภูมิห้องส่วนใหญ่อยู่ใกล้ขอบแถบ (บท 2) และทั้ง e⁻ กับ hole ต่างเจอ กำแพงพลังงาน ที่กันไม่ให้เข้าไปในโซนนั้น

ความหนาแน่นประจุ ρ(x) (สมการ 5.6) — ให้ p อยู่ซ้าย (x<0), n อยู่ขวา (x>0) ρ(x) = −q N_A เมื่อ −x_p < x < 0 (ฝั่ง p: acceptor ไอออนลบ) ρ(x) = +q N_D เมื่อ 0 < x < x_n (ฝั่ง n: donor ไอออนบวก) ρ(x) = 0 นอกช่วงนั้น (เป็นกลางทางไฟฟ้า)

5.4 แก้สมการ Poisson → E(x), V(x) ⭐⭐⭐

สมการ Poisson ใน 1 มิติ (สมการ 5.7) · ε_r = ค่าคงที่ไดอิเล็กทริกสัมพัทธ์, ε₀ = สภาพยอมของสุญญากาศ dE(x)/dx = ρ(x) / (ε_r ε₀)

ก้าวที่ 1: อินทิเกรตครั้งที่ 1 → E(x)

เงื่อนไขขอบ: สนามไฟฟ้าต้องเป็นศูนย์นอก depletion region (เพราะข้างนอกเป็นกลาง)

สมการ 5.9 E(x) = −(q N_A / ε_r ε₀)·(x + x_p) เมื่อ −x_p < x < 0 E(x) = −(q N_D / ε_r ε₀)·(x_n − x) เมื่อ 0 < x < x_n E(x) = 0 นอกช่วงนั้น
🔑 อ่านผลลัพธ์นี้ให้เป็น
  • E(x) เป็น รูปสามเหลี่ยม (เชิงเส้นสองท่อน)
  • E เป็นลบตลอดใน junction ⇒ สนามชี้ไปทาง −x คือ จากฝั่ง n ไปฝั่ง p ✓ (สอดคล้องกับที่ว่าเส้นแรงเริ่มจากประจุบวก)
  • สนามแรงที่สุดที่ x = 0 (รอยต่อ)
⭐ สนามสูงสุด (สมการ 5.10) — เขียนได้ 2 แบบ ต้องได้ค่าเท่ากัน E_max = E(0) = −(q N_A / ε_r ε₀)·x_p = −(q N_D / ε_r ε₀)·x_n ⭐ จากบรรทัดบน ตัดค่าคงที่ออกได้ทันที → สมการสมดุลประจุของ junction (สมการ 5.11) N_A · x_p = N_D · x_n
💡 ความหมายทางฟิสิกส์ของ NAxp = NDxn ประจุลบที่เก็บไว้ฝั่ง p = ประจุบวกที่เก็บไว้ฝั่ง n (จำนวนเท่ากันเป๊ะ)
เป็นผลโดยตรงจาก กฎของเกาส์ (Gauss's Law)

ผลที่ตามมาที่ต้องพูดได้: ฝั่งที่โดปหนักกว่า จะมี depletion region บางกว่า
เช่น NA = 400×ND ⇒ xp = xn/400

ก้าวที่ 2: อินทิเกรตครั้งที่ 2 → V(x) และ Vbi

สมการ 5.12, 5.13 — เริ่มจากฝั่ง p เพราะศักย์ต่ำสุดอยู่ที่นั่น V(x) = − ∫[−x_p → x] E(x) dx → ได้รูป พาราโบลา V_bi = − ∫[−x_p → x_n] E(x) dx = (q / 2ε_r ε₀) · ( N_A x_p² + N_D x_n² )

💡 ทางลัด: Vbi = พื้นที่ใต้กราฟ E(x) (พื้นที่สามเหลี่ยม = ½ × ฐาน × สูง = ½·W·|Emax|)

ก้าวที่ 3: หาความกว้าง depletion region

รวมสมการ 5.11 (สมดุลประจุ) กับ 5.13 (Vbi) แล้วแก้หา xn, xp

⭐⭐⭐ สูตรที่ต้องใช้ในข้อสอบแน่นอน (สมการ 5.14–5.16) x_n = [ (2 ε_r ε₀ / q) · N_A / (N_D (N_A + N_D)) · V_bi ]^0.5 ← ฝั่ง n x_p = [ (2 ε_r ε₀ / q) · N_D / (N_A (N_A + N_D)) · V_bi ]^0.5 ← ฝั่ง p W = x_n + x_p = [ (2 ε_r ε₀ / q) · (N_A + N_D)/(N_A N_D) · V_bi ]^0.5
⚠️ จุดที่คนพลาดบ่อยที่สุดในสูตรนี้ xn (ฝั่ง n) มี NA อยู่บนเศษ · xp (ฝั่ง p) มี ND อยู่บนเศษ
มัน "สลับกัน" — จำว่า "ฝั่งไหน ใช้โดปของอีกฝั่ง"
เช็กด้วยสามัญสำนึก: NA ใหญ่มาก ⇒ xn ต้องใหญ่ และ xp ต้องเล็ก ✓

5.5 กราฟ 3 ชั้น ที่ต้องวาดได้ ⭐⭐⭐ (= HW2 ข้อ 5)

แผนภาพนี้คือคำตอบของ HW2 ข้อ 5 — จำลำดับ ρ → (อินทิเกรต) → E → (อินทิเกรต) → V
🔑 เช็กลิสต์เวลาวาดกราฟในข้อสอบ (ห้ามลืม!)
  1. ทำเครื่องหมาย −xp, 0, xn ตรงกันทั้ง 3 กราฟ (ลากเส้นประเชื่อม)
  2. ρ: กล่องสี่เหลี่ยม 2 อัน สูง −qNA และ +qND · พื้นที่ต้องเท่ากัน
  3. E: สามเหลี่ยม อยู่ใต้แกน (ค่าลบ) ยอดแหลมที่ x=0 · ระบุ Emax
  4. V: เพิ่มขึ้นจากฝั่ง p ไปฝั่ง n · เป็นเส้นโค้ง ไม่ใช่เส้นตรง · ระบุ Vbi
  5. ถ้าโจทย์สลับให้ n อยู่ซ้าย p อยู่ขวา → ทุกกราฟกลับด้าน! (HW2 ข้อ 5 เป็นแบบนี้ — ต้องอ่านรูปให้ดี)

5.6 ตัวอย่างคำนวณเต็มรูปแบบ

📝 ตัวอย่างจากสไลด์ · abrupt Si junction · NA=4×10¹⁸, ND=10¹⁶ cm⁻³ · T=300K

ก้าว 1 — V_bi V_bi = 0.026 × ln( (4×10¹⁸ × 10¹⁶) / (10¹⁰)² ) = 0.026 × ln(4×10¹⁴) = 0.026 × 33.62 = 0.87 V ✓ < 1.12 V ก้าว 2 — x_n (ใช้ ε_r = 11.8, ε₀ = 8.854×10⁻¹⁴ F/cm) x_n = [ (2×11.8×8.854×10⁻¹⁴ / 1.6×10⁻¹⁹) × (4×10¹⁸)/(10¹⁶ × 4.01×10¹⁸) × 0.87 ]^0.5 = 3.3×10⁻⁵ cm = 0.33 µm ก้าว 3 — x_p x_p = [ ... × (10¹⁶)/(4×10¹⁸ × 4.01×10¹⁸) × 0.87 ]^0.5 = 8.4×10⁻⁸ cm = 0.84 nm ก้าว 4 — E_max E_max = −(q N_D / ε_r ε₀) · x_n = −51 kV/cm
✅ ตรวจสอบความสมเหตุสมผล (ควรเขียนในข้อสอบด้วย) ① NA/ND = 400 ⇒ xn/xp ควรเป็น 400 → 3.3×10⁻⁵/8.4×10⁻⁸ ≈ 393 ✓
② ฝั่งที่โดปหนัก (p) มี depletion บางมาก ✓
③ ประโยคสรุปที่อาจารย์เน้น: "โดปหนัก ⇒ depletion แคบ · โดปเบา ⇒ depletion กว้าง"
