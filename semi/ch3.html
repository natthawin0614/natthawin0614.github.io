3.1 Drift — การเคลื่อนที่ในสนามไฟฟ้า

🌡️ ภาพก่อนใส่สนาม ที่อุณหภูมิห้อง พาหะวิ่ง เร็วมากแต่สะเปะสะปะ (random thermal motion) ชนกับความไม่สมบูรณ์ของผลึกตลอดเวลา
→ แม้วิ่งเร็วมาก แต่ กระแสสุทธิ = 0 เพราะไปทุกทิศเท่ากัน
พอใส่สนามไฟฟ้า → เกิดการ "ไหลเอื่อย ๆ" (slow drift) ซ้อนทับบนการเดินสุ่ม → เกิดกระแส
ความเร็วดริฟต์ (สมการ 3.1, 3.2) — τ = relaxation time = เวลาเฉลี่ยระหว่างการชน โฮล : v_d,p = +(qτ / m*ₚ) · E อิเล็กตรอน : v_d,n = −(qτ / m*ₙ) · E ← เครื่องหมายลบ = วิ่งสวนสนาม

Mobility (μ) — "ความคล่องตัว"

สมการ 3.3–3.6 μₚ = qτ / m*ₚ μₙ = qτ / m*ₙ [หน่วย: cm²/V·s] ⇒ v_d,p = +μₚ E v_d,n = −μₙ E

ตีความ: μ บอกว่าพาหะ "ถูกสนามไฟฟ้าเร่งได้ง่ายแค่ไหน" — m* เล็ก ⇒ μ ใหญ่ · τ ยาว (ชนน้อย) ⇒ μ ใหญ่

⚠️ ข้อยกเว้นที่ออกสอบ: Velocity saturation ความสัมพันธ์ vd ∝ E เป็นเชิงเส้นเฉพาะที่สนามปานกลาง
ที่สนามสูงมาก ๆ → vd อิ่มตัว (saturate) และ e⁻ กับ hole อิ่มตัวที่ค่าเดียวกัน
เหตุผล: เมื่อ vd เทียบเท่าความเร็วเชิงความร้อนแล้ว พลังงานที่สนามป้อนเข้าไปจะถ่ายเทให้ผลึก (lattice) แทนที่จะไปเร่งพาหะให้เร็วขึ้น

μ ขึ้นกับอุณหภูมิยังไง — กราฟที่ต้องวาดเป็น

μ ถูกกำหนดโดย อัตราการชนรวม ซึ่งมี 2 กลไกหลักที่แข่งกัน

สมการ 3.7–3.9 ① Lattice scattering (การสั่นของอะตอมจากความร้อน) : 1/τ_l ∝ T^(+3/2) ② Ionized-dopant scattering (ชนกับไอออนของสารเจือ) : 1/τ_ii ∝ T^(−3/2) รวมกันแบบ Matthiessen: 1/τ = 1/τ_l + 1/τ_ii
μ มีพฤติกรรม ไม่ทางเดียว (non-monotonic) เพราะสองกลไกแข่งกันคนละทิศ
ช่วงกลไกที่ครอบงำเหตุผลμ ∝
T ต่ำionized dopantพาหะวิ่งช้า (vthermalต่ำ) → ถูกไอออนดึงเบี่ยงได้ง่าย · และผลึกแทบไม่สั่นT+3/2 (μ เพิ่มตาม T)
T สูงlattice vibrationอะตอมสั่นแรง = ผลึกไม่เป็นระเบียบ → ชนบ่อยT−3/2 (μ ลดตาม T)

μ ขึ้นกับความเข้มข้นการโดปยังไง

  • โดปน้อย → lattice scattering ครอบงำ → μ ไม่ขึ้นกับการโดป (กราฟราบ)
  • โดปมาก → ไอออนเยอะขึ้น → ionized impurity scattering ชนะ → μ ลดลง
🔑 นี่คือเหตุผลว่าทำไมโจทย์ถึงชอบให้ μ คนละค่าตอนโดปกับไม่โดป เช่นสไลด์: Si บริสุทธิ์ μn=1350 แต่พอโดป ND=10¹⁷ ให้ใช้ μn=800 cm²/Vs (ลดลงเพราะ ionized impurity scattering)
อย่าเผลอใช้ค่าเดิม!

3.2 กระแส Drift และ Resistivity

📐 ที่มาของ J (อาจารย์ derive ให้ในสไลด์) พิจารณาผิวอ้างอิงพื้นที่ A · โฮลความเข้มข้น p วิ่งด้วย vp
ในเวลา 1 หน่วย โฮลที่ข้ามผิวได้ = โฮลในกล่องปริมาตร A·vp = p·A·vp ตัว
กระแส = ประจุต่อเวลา = q·p·A·vp · ความหนาแน่นกระแส J = กระแส/A = q·p·vp
สมการ 3.10, 3.11 — สังเกตว่าไม่มีเครื่องหมายลบทั้งคู่! J_P|drift = q p v_d,p = q p μₚ E J_N|drift = q n |v_d,n| = q n μₙ E
🔑 ทำไมกระแสของ e⁻ กับ hole ถึง "บวกกัน" อิเล็กตรอน: ประจุลบ × วิ่งสวนสนาม = ลบ × ลบ = บวก
โฮล: ประจุบวก × วิ่งตามสนาม = บวก × บวก = บวก
→ ทั้งคู่ชี้ทางเดียวกับสนาม ⇒ กระแสรวมกัน ไม่หักล้าง
⭐ Ohm's law และ Resistivity (สมการ 3.12–3.14) J = σE = E/ρ J = J_P + J_N = ( q p μₚ + q n μₙ ) E ⇒ σ = q(n μₙ + p μₚ) [S/cm] ⇒ ρ = 1 / [ q(n μₙ + p μₚ) ] [Ω·cm]
กรณีโดปข้างเดียว (สมการ 3.15, 3.16) — ตัวส่วนตัวเดียวหายไป n-type หนัก (N_D ≫ N_A): ρ = 1 / (q μₙ N_D) p-type หนัก (N_A ≫ N_D): ρ = 1 / (q μₚ N_A) ⚠️ ใช้ได้เมื่อสมมติว่า dopant ionize เต็มที่เท่านั้น

📝 ตัวอย่างจากสไลด์ (ออกสอบแน่ ๆ)

Si @300K · μn=1350, μp=480 cm²/Vs · ni=10¹⁰ cm⁻³ · จงหา ρ ของ Si บริสุทธิ์ และเมื่อโดป ND=10¹⁷ (ใช้ μn=800)

Si บริสุทธิ์ (n = p = n_i): ρ = 1/[q·n_i·(μₙ+μₚ)] = 1/[1.6×10⁻¹⁹ × 10¹⁰ × (1350+480)] = 3.4×10⁵ Ω·cm ← สูงมาก แทบเป็นฉนวน โดป N_D = 10¹⁷ cm⁻³ (n ≈ N_D, μₙ = 800): ρ = 1/(q μₙ N_D) = 1/[1.6×10⁻¹⁹ × 800 × 10¹⁷] = 0.08 Ω·cm ← ลดลง 4 ล้านเท่า!

💡 นี่คือพลังของการโดป ที่บทที่ 1 พูดถึง แสดงเป็นตัวเลขจริง

💡 การประยุกต์จริง กราฟ ρ vs doping ในสไลด์ใช้ วัดความต้านทาน → อ่านย้อนกลับหาความเข้มข้นการโดปได้ (เป็นวิธีมาตรฐานในโรงงาน)

3.3 Diffusion — การแพร่

🔑 ความต่างที่ต้องพูดได้ (คำถาม concept ยอดฮิต)
DriftDiffusion
แรงขับสนามไฟฟ้า Eความร้อน (thermal energy)
สาเหตุมีแรงดันตกคร่อมมี ความชันความเข้มข้น (concentration gradient)
เป้าหมาย—ให้พาหะกระจายตัว สม่ำเสมอ
สัมประสิทธิ์μ (mobility)D (diffusion coefficient) [cm²/s]
ข้อต่างสำคัญจากการแพร่ของก๊าซทั่วไป: พาหะใน semiconductor มีประจุ → การแพร่จึงสร้างกระแสไฟฟ้าจริง ๆ
Fick's Law — F = ฟลักซ์ (จำนวนอนุภาคผ่านพื้นที่ 1 หน่วยต่อเวลา), η = ความเข้มข้น F = −D ∇η (เครื่องหมายลบ = ไหลจากมากไปน้อย)
⭐ กระแสแพร่ (สมการ 3.17, 3.18) — ระวังเครื่องหมาย! โฮล : J_P|diff = − q D_p · dp/dx อิเล็กตรอน : J_N|diff = + q D_n · dn/dx
⚠️ ทำไมเครื่องหมายต่างกัน — โจทย์ชอบดักตรงนี้ โฮลกับอิเล็กตรอนแพร่ไปทางเดียวกัน (จากที่เข้มข้นมาก → น้อย) แต่ประจุตรงข้าม
→ โฮลแพร่ไป +x ⇒ กระแสไป +x · อิเล็กตรอนแพร่ไป +x ⇒ กระแสไป −x
"กระแสแพร่ไหลไปในทิศที่ p ลดลง หรือ n เพิ่มขึ้น" (ประโยคในสไลด์)
⭐⭐ กระแสรวม = drift + diffusion (สมการ 3.19–3.21) J_P = q p μₚ E − q D_p (dp/dx) J_N = q n μₙ E + q D_n (dn/dx) J = J_P + J_N

3.4 สมดุล: drift = −diffusion ⭐ (กุญแจสู่บท 5)

ที่สมดุลความร้อนและไม่มีสนามภายนอก → กระแสสุทธิ = 0
และเพราะ e⁻ กับ hole เคลื่อนที่อิสระต่อกัน ⇒ ต้องเป็นศูนย์แยกกันทั้งคู่

สมการ 3.22, 3.23 J_P|drift = − J_P|diff J_N|drift = − J_N|diff
🔑🔑 ข้อสรุปที่ "น่าทึ่ง" ที่สุดของบทนี้ (อาจารย์เขียนว่า VERY INTERESTING) กระแส drift จะเป็นศูนย์ก็ต่อเมื่อไม่มีความชันความเข้มข้นเท่านั้น
ถ้ามีความชันความเข้มข้นอยู่ → จะมีกระแส diffusion → ต้องมีกระแส drift มาหักล้าง
แม้จะไม่มีแบตเตอรี่หรือแรงดันจากภายนอกเลย!

แล้ว drift มาจากไหน? → มาจาก สนามไฟฟ้าในตัว (BUILT-IN electric field) ที่ตัว diffusion เองสร้างขึ้นมา
← นี่แหละคือหลักการทำงานของ pn junction ทั้งอัน (บท 5)

3.5 Einstein Relation ⭐⭐

สังหรณ์: ทั้ง drift และ diffusion เกิดจากการชนแบบเดียวกัน (τ ตัวเดียวกัน) → μ กับ D จึงต้องเกี่ยวข้องกัน

ดูการพิสูจน์ (สไลด์ derive ให้ — อาจออกเป็นอัตนัย)
ก้าวที่ 1 — เริ่มจากสมดุลของอิเล็กตรอน (สมการ 3.24): q μₙ n E(x) + q D_n (dn/dx) = 0 ก้าวที่ 2 — ใช้ความสัมพันธ์จากบท 2 (สมการ 2.32): E(x) = (1/q)·dE_i/dx ก้าวที่ 3 — ใช้ n = n_i·exp[(E_F−E_i)/k_BT] จากบท 2 หา dn/dx (E_F คงที่เพราะอยู่ในสมดุล, ตัวที่แปรตาม x คือ E_i) dn/dx = −(n/k_BT)·(dE_i/dx) = −(q/k_BT)·n·E(x) ...(3.25) ก้าวที่ 4 — แทน (3.25) ลงใน (3.24): q μₙ n E + q D_n · [−(q/k_BT) n E] = 0 q n E [ μₙ − q D_n/k_BT ] = 0 ⇒ D_n/μₙ = k_BT/q

ทำแบบเดียวกันกับโฮลได้ Dp/μp = kBT/q เช่นกัน

⭐⭐ Einstein relation (สมการ 3.26, 3.27) D_n/μₙ = D_p/μₚ = k_B T / q @ 300 K: k_BT/q = (1.38×10⁻²³ × 300)/(1.6×10⁻¹⁹) = 0.026 V ← จำค่านี้!
⚠️ เงื่อนไขที่ใช้ได้ (คำถาม concept) การพิสูจน์ใช้ n = n_i e^((E_F−E_i)/kT) ซึ่งมาจากสมมติฐาน non-degenerate
→ Einstein relation ใช้ไม่ได้กับสาร degenerate (โดปหนักมาก)

3.6 ตัวอย่างประยุกต์ 2 ข้อจากสไลด์ (ออกเป็นอัตนัยได้เลย)

📝 ตัวอย่าง A — Built-in field จาก doping profile แบบ exponential ⭐

โจทย์: Si intrinsic ที่ 300 K ถูกโดป donor จากด้านหนึ่งให้ ND = N₀·exp(−ax) โดย ND ≫ ni
จงหา Ex ที่สมดุล และคำนวณเมื่อ a = 1 µm⁻¹

เนื่องจาก N_D ≫ n_i ⇒ n(x) ≈ N_D(x) = N₀ e^(−ax) ที่สมดุล กระแสอิเล็กตรอนต้องเป็นศูนย์ (สมการ 3.25): dn/dx = −(q/k_BT)·n·E(x) หา dn/dx จาก profile: dn/dx = N₀·(−a)·e^(−ax) = −a·n(x) จับสองอันเท่ากัน: −a·n = −(q/k_BT)·n·E(x) ⇒ E(x) = (k_B T / q)·a ← คงที่! ไม่ขึ้นกับ x แทนค่า a = 1 µm⁻¹ = 10⁴ cm⁻¹: E = (1.38×10⁻²³ × 300)/(1.6×10⁻¹⁹) × 10⁴ = 0.026 × 10⁴ = 259 V/cm
✅ 2 ประโยคที่ต้องเขียนตอบด้วย (สไลด์เน้น) ① สนามเป็นบวก เพราะอิเล็กตรอนแพร่ออกไป ทิ้ง ไอออน donor ที่มีประจุบวก ไว้ข้างหลัง
② สนามคงที่ (ไม่ขึ้นกับ x) → แถบพลังงานจะเอียงด้วยความชันคงที่ ตามที่เรียนในบท 2

📝 ตัวอย่าง B — กระแสแพร่จาก profile เชิงเส้น

โจทย์: Si @300K โดป acceptor 10¹⁵ cm⁻³ (⇒ p-type, e⁻ = minority) · ฉีด e⁻ เข้าไปที่ x=0 ให้ n=10¹¹ cm⁻³ ลดลงเชิงเส้นจนถึงค่าสมดุลที่ x=10 µm · μn=1300 cm²/Vs · หา JN,diff

ก้าว 1 — หา D_n จาก Einstein: D_n = μₙ·(k_BT/q) = 1300 × 0.026 = 33.8 cm²/s ก้าว 2 — หา n ที่สมดุล (ปลายทาง): n₀ = n_i²/N_A = (10¹⁰)²/10¹⁵ = 10⁵ cm⁻³ ← เล็กมากเทียบกับ 10¹¹ ทิ้งได้ ก้าว 3 — ความชัน (เชิงเส้น ⇒ dn/dx = Δn/Δx): dn/dx = (10⁵ − 10¹¹)/(10×10⁻⁴ cm) ≈ −10¹¹/10⁻³ = −10¹⁴ cm⁻⁴ ก้าว 4 — แทนสูตร: J_N|diff = q D_n (dn/dx) = (1.6×10⁻¹⁹)(33.8)(−10¹⁴) ≈ −0.54 A/cm²

👉 เครื่องหมายลบ = กระแสไหลไปทาง −x ทั้งที่อิเล็กตรอนเคลื่อนที่ไปทาง +x (เพราะประจุลบ) ← ต้องอธิบายให้ได้!
