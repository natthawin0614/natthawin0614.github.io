2.1 สูตรมาสเตอร์ — จำแค่นี้ก็เข้าใจทั้งบท

🔑 แนวคิดเดียวที่ทั้งบทนี้ตั้งอยู่
จำนวนพาหะ = ∫ (มีเก้าอี้กี่ตัว) × (โอกาสที่เก้าอี้จะมีคนนั่ง) dE = ∫ g(E) × f(E) dE

ส่วนที่ 1: g(E) — Density of States (มีเก้าอี้กี่ตัว)

g(E) = จำนวนสถานะที่อนุญาต ต่อหน่วยปริมาตร ต่อหน่วยพลังงาน

ที่มาโดยย่อ: นับสถานะใน k-space โดยหาปริมาตรของเปลือกทรงกลมบาง ๆ รัศมี k ถึง k+dk (Vshell=4πk²dk) แล้วแปลง k → E

ในสารกึ่งตัวนำ — g(E) ต้องเป็น "ศูนย์" ภายใน forbidden gap! Conduction band: g_c(E) = (1/π²ℏ³) · √(2 m*ₙ³) · √(E − E_c) สำหรับ E ≥ E_c Valence band : g_v(E) = (1/π²ℏ³) · √(2 m*ₚ³) · √(E_v − E) สำหรับ E ≤ E_v ใน gap : g(E) = 0
💡 ธรรมเนียมการวางแกนพลังงานในสไลด์นี้ อาจารย์กำหนดให้ ยอด valence band Ev = 0 เป็นจุดอ้างอิง → ดังนั้น Ec = Eg
เวลาเห็นสูตร g_c(E) ∝ √(E − E_g) ในสไลด์/สรุปรุ่นพี่ ก็คืออันเดียวกับ √(E − E_c) นั่นเอง

รูปร่าง: เป็นรากที่สอง — โตจาก 0 ที่ขอบแถบ แล้วค่อย ๆ กว้างขึ้น (กราฟหันหลังชนกันคนละฝั่งของ gap)

ส่วนที่ 2: f(E) — Fermi–Dirac function (โอกาสมีคนนั่ง)

ความน่าจะเป็นที่สถานะพลังงาน E จะถูกอิเล็กตรอนครอบครอง ที่อุณหภูมิ T f(E,T) = 1 / [ exp((E − E_F)/k_B T) + 1 ]
ที่ T=0 เป็นขั้นบันไดคมที่ EF · พอ T สูงขึ้น ขั้นบันได "มน" (round) เพราะบางสถานะใต้ EF ว่างลง อิเล็กตรอนย้ายขึ้นไปสถานะพลังงานสูงกว่า
🔑 3 ข้อเท็จจริงของ f(E) ที่ออกสอบแน่
  • f(EF) = 0.5 เสมอ ทุกอุณหภูมิ (แทน E=EF จะได้ 1/(e⁰+1)=1/2)
  • ความน่าจะเป็นที่สถานะจะว่าง (= มี hole) คือ 1 − f(E)
  • อุณหภูมิมีผลเปลี่ยนการครอบครองเฉพาะในหน้าต่างแคบ ๆ กว้าง ~3.5kBT รอบ EF เท่านั้น

2.2 อินทิเกรตออกมาเป็นสูตรใช้งาน

อินทิกรัลเต็ม (ยาก แก้ตรง ๆ ไม่ได้) n = ∫[E_c → ∞] g_c(E) · f(E) dE p = ∫[−∞ → E_v] g_v(E) · [1 − f(E)] dE
🔑 กุญแจ: สมมติฐาน Non-degenerate
E − E_F > 3.5 k_B T (สมการ 2.7)
เมื่อ (E−EF) ใหญ่พอ → exp(...)≫1 → ตัดเลข 1 ในส่วนทิ้งได้ → Fermi-Dirac กลายเป็น Boltzmann → อินทิกรัลกลายเป็นอินทิกรัลมาตรฐานที่แก้ได้!
แปลเป็นภาษาคน: EF ต้องอยู่ "ลึกใน gap" ไม่ชิดขอบแถบ = โดปไม่หนักเกินไป
ถ้าโดปหนักมากจน EF เข้าไปในแถบ → เรียก degenerate → สูตรทั้งบทนี้ใช้ไม่ได้ (ข้อสอบชอบถาม!)
⭐ สูตรทองของบทนี้ (สมการ 2.8, 2.9) n = N_c · exp[ −(E_c − E_F)/k_B T ] ; N_c = 2[ 2π m*ₙ k_B T / h² ]^(3/2) p = N_v · exp[ −(E_F − E_v)/k_B T ] ; N_v = 2[ 2π m*ₚ k_B T / h² ]^(3/2)

Nc, Nv เรียกว่า "effective density of states" — ตีความว่า: แทนที่จะมีสถานะกระจายทั่วทั้ง band ให้คิดเสมือนว่ามี Nc สถานะกระจุกอยู่ที่ Ec พอดี

ค่าที่ควรจำ (Si, 300 K)ค่า
Nc (m*n=1.18m₀)≈ 3.25×10¹⁹ cm⁻³ = 3.25×10²⁵ m⁻³
Nv (m*p=0.81m₀)≈ 1.83×10¹⁹ cm⁻³
ni(Si, 300K)≈ 10¹⁰ cm⁻³

2.3 สาร Intrinsic — หา EF และ ni

ตรรกะ: ในสารบริสุทธิ์ ทุก e⁻ ใน CB เกิดจากการกระตุ้นจาก VB ⇒ ทิ้ง hole ไว้ 1 ตัวเสมอ ⇒ n = p ทุกอุณหภูมิ
เอาสมการ 2.8 = 2.9 แล้วแก้หา EF

⭐ ตำแหน่ง Fermi level ของสาร intrinsic (สมการ 2.10) E_F(T) = E_g/2 + (3/4) k_B T · ln( m*ₚ / m*ₙ ) ↑ พจน์หลัก ↑ พจน์แก้เล็ก ๆ (มักน้อยกว่ามาก)
🔑 ข้อสรุปที่ต้องพูดได้ พจน์ที่สองเล็กมากเมื่อเทียบพจน์แรก (kBT ≈ 26 meV แต่ Eg ≈ 1–3 eV)
→ EF ของสาร intrinsic อยู่เกือบกึ่งกลาง gap พอดี เราเรียกมันว่า Ei (intrinsic Fermi level)

📝 ตัวอย่างจากสไลด์ — Si ที่ 300 K (ต้องทำได้!)

โจทย์: Eg=1.12 eV, m*n=1.18m₀, m*p=0.81m₀ · จงหา n และ p

ก้าวที่ 1 — หา E_F E_g/2 = 0.56 eV (3/4)k_BT·ln(m*ₚ/m*ₙ) = (3/4)(8.617×10⁻⁵ × 300)·ln(0.81/1.18) = 0.75 × 0.02585 × (−0.3765) = −7.3 meV = −0.007 eV E_F = 0.56 − 0.007 = 0.553 eV (วัดจาก E_v = 0) ก้าวที่ 2 — E_c − E_F = 1.12 − 0.553 = 0.567 eV ก้าวที่ 3 — แทนในสูตรทอง n = N_c·exp[−(E_c−E_F)/k_BT] = 3.25×10²⁵ m⁻³ × exp(−0.567 / 0.02585) = 3.25×10²⁵ × e^(−21.93) = 10¹⁶ m⁻³ = 10¹⁰ cm⁻³ เนื่องจาก intrinsic ⇒ p = n = 10¹⁰ cm⁻³

2.4 สาร Extrinsic — คำนวณ n, p เมื่อโดป ⭐⭐

เครื่องมือ 2 ชิ้น

① Mass action law (สมการ 2.12) — เอา 2.8 × 2.9 n · p = N_c N_v · exp(−E_g/k_B T) = n_i² ← คงที่เสมอที่อุณหภูมิเดียวกัน ไม่ว่าโดปยังไง ② Charge-neutrality equation (สมการ 2.13) — ผลึกต้องเป็นกลางทางไฟฟ้า p − n + N_D⁺ − N_A⁻ = 0
💡 ตีความสมการสมดุลประจุ ทุกครั้งที่ donor ปล่อย e⁻ ออกไป → ตัว donor เหลือประจุบวก (ND⁺)
ทุกครั้งที่ acceptor รับ e⁻ (ปล่อย hole) → ตัว acceptor เหลือประจุลบ (NA⁻)
รวมประจุบวกทั้งหมด (p + ND⁺) ต้องเท่ากับประจุลบทั้งหมด (n + NA⁻)
HW1 ข้อ 4 เขียนในรูป n + N_A⁻ = p + N_D⁺ ซึ่งเหมือนกันเป๊ะ

เอา ① กับ ② มารวมกัน → สมการกำลังสอง

n² − (N_D⁺ − N_A⁻)n − n_i² = 0 p² − (N_A⁻ − N_D⁺)p − n_i² = 0 แก้ด้วยสูตรกำลังสอง (ทิ้งรากลบ เพราะความหนาแน่นต้องเป็นบวก): n = (N_D − N_A)/2 + √[ ((N_D − N_A)/2)² + n_i² ] p = (N_A − N_D)/2 + √[ ((N_A − N_D)/2)² + n_i² ] หมายเหตุ: ที่ 300 K สมมติ ionize เต็มที่ ⇒ N_D⁺ = N_D , N_A⁻ = N_A

🚀 ทางลัดที่ใช้จริง 95% ของโจทย์

เมื่อโดปมากกว่า ni เยอะ ๆ (ซึ่งเป็นเกือบทุกกรณี)
n-type หนัก (N_D ≫ N_A, n_i): n ≈ N_D และ p = n_i²/N_D p-type หนัก (N_A ≫ N_D, n_i): p ≈ N_A และ n = n_i²/N_A ถ้าโดปทั้งสองชนิด → ใช้ net doping: n ≈ N_D − N_A (ถ้า N_D > N_A) p ≈ N_A − N_D (ถ้า N_A > N_D)
ได้คำตอบเท่ากับใช้สมการกำลังสองเต็ม ๆ เป๊ะ ๆ — สไลด์พิสูจน์ให้ดูแล้ว

📝 ตัวอย่างจากสไลด์ (ni=10¹⁰, NA=10¹⁵, ND=10¹⁶ cm⁻³)

n = (10¹⁶−10¹⁵)/2 + √[ ((10¹⁶−10¹⁵)/2)² + (10¹⁰)² ] = 4.5×10¹⁵ + √[ 2.025×10³¹ + 10²⁰ ] ← พจน์ n_i² เล็กจนทิ้งได้ ≈ 9×10¹⁵ cm⁻³ (= N_D − N_A นั่นเอง!) p = n_i²/n = 10²⁰ / 9×10¹⁵ = 1.1×10⁴ cm⁻³

👉 หา p อย่าไปแก้สมการกำลังสองอีกรอบ — ใช้ np=ni² เอาสิ ง่ายกว่ามาก

⚠️ กับดัก: โดปหลายตัวพร้อมกัน (HW1 ข้อ 3!) โจทย์ให้ Si โดป Sb 10¹⁵ + P 10¹⁶ + As 10¹⁷ cm⁻³
Sb, P, As เป็นหมู่ V หมด = donor ทั้ง 3 ตัว → ต้องบวกกัน:
ND,net = 10¹⁵+10¹⁶+10¹⁷ = 1.11×10¹⁷ cm⁻³ = n · แล้ว p = (10¹⁰)²/1.11×10¹⁷ = 9×10² cm⁻³ → n-type

พอโดป B 10¹⁸ เพิ่ม (หมู่ III = acceptor) → Nnet = NA−ND = 10¹⁸ − 1.11×10¹⁷ = 8.89×10¹⁷ = p → กลายเป็น p-type!
ต้องท่องได้ว่าใครหมู่ III ใครหมู่ V: B, Al, Ga, In = acceptor · P, As, Sb = donor

2.5 ตำแหน่ง EF ในสารที่โดปแล้ว ⭐⭐

ใช้ Ei (ระดับ Fermi ของสารบริสุทธิ์ ≈ กลาง gap) เป็นจุดอ้างอิง แล้วเขียน n, p เทียบกับ ni

⭐⭐ สูตรที่ใช้บ่อยที่สุดในบทนี้และบท 5 (สมการ 2.23, 2.24) n = n_i · exp[ (E_F − E_i)/k_B T ] p = n_i · exp[ (E_i − E_F)/k_B T ] พลิกกลับ (สมการ 2.25): E_F − E_i = k_B T · ln(n/n_i) = −k_B T · ln(p/n_i)
✅ ทำไมสูตรนี้ดีกว่า n=Nce^(...) สมการ 2.8/2.9 ต้องรู้ Nc, Nv, m* → คำนวณยาว
สมการ 2.23/2.24 ใช้แค่ ni ที่โจทย์ให้มา → เร็วกว่ามาก และใช้ได้กับสารทุกชนิด (non-degenerate)
กรณีโดปหนัก (สมการ 2.26, 2.27) — แค่แทน n=N_D, p=N_A n-type: E_F − E_i = +k_B T · ln( N_D / n_i ) → E_F ขยับ ขึ้น ใกล้ E_c p-type: E_F − E_i = −k_B T · ln( N_A / n_i ) → E_F ขยับ ลง ใกล้ E_v
EF คือมาตรวัดชนิดสาร — อยู่ครึ่งบน = n-type, กลาง = intrinsic, ครึ่งล่าง = p-type
⚠️ ข้อจำกัดที่ออกสอบบ่อย ถ้าโดปหนักมาก ๆ จน EF เข้าไปในแถบ (แตะ Ec หรือ Ev) → สารกลายเป็น degenerate
→ สูตรทั้งหมดในบทนี้ใช้ไม่ได้ เพราะละเมิดเงื่อนไข E−EF > 3.5kBT

ที่มาของการกระจายพาหะ (รูป 4 คอลัมน์ในสไลด์ — ต้องวาดเป็น)

สไลด์แสดง 4 คอลัมน์เรียงกัน: โครงสร้างแถบ → g(E) → f(E) → การครอบครองจริง g(E)·f(E)

ชนิดสารEF อยู่ไหนพื้นที่ใต้กราฟ e⁻พื้นที่ใต้กราฟ hole
Intrinsicกลาง gapเท่ากันพอดี
n-typeครึ่งบนใหญ่เล็ก
p-typeครึ่งล่างเล็กใหญ่

ประโยคที่อาจารย์เน้น: ใน n-type “อิเล็กตรอนมาจากทั้ง donor และตัวผลึกเอง ส่วน hole มาจากตัวผลึกอย่างเดียว” (และสลับกันสำหรับ p-type)

2.6 พลังงานจลน์/ศักย์ และ Band Bending ⭐⭐

หัวข้อนี้ดูนามธรรม แต่เป็นรากฐานทั้งหมดของบท 5 — ถ้าตรงนี้ไม่แน่น pn junction จะงงมาก

① ทิศทางของพลังงาน

  • อิเล็กตรอน: พลังงานเพิ่มขึ้นเมื่อ ขึ้นบน ใน conduction band ↑
  • โฮล: พลังงานเพิ่มขึ้นเมื่อ ลงล่าง ใน valence band ↓ (สวนทางกัน!)

เหตุผล: ถ้าจะกระตุ้น e⁻ จาก VB ขึ้นไปที่ Ec — อิเล็กตรอนที่อยู่ลึกกว่าใน VB ต้องใช้พลังงานมากกว่า พลังงานอนุรักษ์ ⇒ hole ที่อยู่ลึกกว่าต้องมีพลังงานสูงกว่า

② พลังงานจลน์ vs ศักย์

  • ที่ขอบแถบพอดี (Ec สำหรับ e⁻, Ev สำหรับ hole): ความเร็ว = 0 ⇒ KE = 0 พลังงานทั้งหมดเป็น PE
  • KE ของอิเล็กตรอน = ระยะที่วัดขึ้นจาก Ec · KE ของโฮล = ระยะที่วัดลงจาก Ev
  • แถบแบนราบ (flat bands) = สมดุลความร้อน ไม่มีสนามไฟฟ้า ไม่มีกระแส

③ Band bending — เมื่อมีแรงดันไฟฟ้า

งานที่ทำเพื่อย้ายประจุไปยังจุดที่ศักย์สูงกว่า V (สมการ 2.29, 2.30) โฮล (ประจุ +q): ΔPE_p = +qV → ศักย์สูงขึ้น = พลังงานโฮลสูงขึ้น อิเล็กตรอน (−q): ΔPE_n = −qV → ศักย์สูงขึ้น = พลังงานอิเล็กตรอนต่ำลง
สารเนื้อเดียว (homogeneous) → แรงดันตกแบบเชิงเส้น → แถบ เอียงด้วยความชันคงที่ · และ Eg ต้องคงที่ตลอด (เส้นขนานกัน)
⭐⭐ สมการเชื่อมสนามไฟฟ้ากับความชันของแถบ (สมการ 2.31, 2.32) E = −dV/dx ← นิยามสนามไฟฟ้าทั่วไป E(x) = (1/q)·dE_c/dx = (1/q)·dE_v/dx = (1/q)·dE_i/dx

  • แถบเอียง ⇒ มีสนามไฟฟ้า · ความชันมาก = สนามแรง
  • แถบเอียงขึ้นไปทาง +x ⇒ E เป็นบวก (ชี้ทาง +x)

  1. เขียนสมการ n = ∫g(E)f(E)dE ได้ และบอกว่า g กับ f คืออะไร
  2. f(EF) = ? · โอกาสที่จะเป็น hole = ?
  3. คำนวณ f ที่ E−EF = kBT, 3kBT ได้ (0.268, 0.047)
  4. non-degenerate คือเงื่อนไขอะไร ทำไมต้องมี ถ้าละเมิดเกิดอะไร
  5. เขียน n = Nce^(−(Ec−EF)/kT) และสูตร Nc ได้
  6. ทำไม EF ของ intrinsic อยู่กลาง gap
  7. np = ni² แปลว่าอะไร ใช้เมื่อไหร่
  8. เขียนสมการสมดุลประจุ + อธิบายว่าทำไมมันเป็นจริง
  9. โจทย์ให้ NA, ND, ni → หา n, p ได้ทั้งวิธีลัดและวิธีสมการกำลังสอง
  10. หา EF−Ei จาก n หรือ p ได้ แล้ววาด band diagram พร้อมตัวเลขได้
  11. อธิบาย band bending: ทำไม VB กับ CB เอียงไปทางเดียวกัน แต่ PE ของ e⁻ กับ hole เพิ่มคนละทาง
  12. E(x) = (1/q)dEc/dx — เขียนได้และใช้อ่านกราฟเป็น
