Semiconductors · Energy bands · Holes · Effective mass · Doping
= สรุปรุ่นพี่ "บทที่ 3" · สไลด์ 28 หน้า · เกือบทั้งบทเป็น concept — ปรนัยล้วน

🎯 บทนี้ตอบคำถามว่า “สารกึ่งตัวนำคืออะไร ทำไมมันนำไฟฟ้าได้ ใครเป็นคนพาประจุ และเราคุมมันได้ยังไง”

1.1 สารกึ่งตัวนำคืออะไร

นิยาม: วัสดุที่ค่าการนำไฟฟ้า (conductivity) อยู่ ระหว่าง โลหะกับฉนวน

แบ่งตามองค์ประกอบ

  • Elemental (ธาตุเดี่ยว) — Si, Ge (หมู่ IV), C, Sn
  • Compound (สารประกอบ) — ส่วนใหญ่ในธรรมชาติเป็นแบบนี้
    • IV–IV: SiC
    • III–V: GaAs, GaN, GaP, AlP, AlAs
    • II–VI: ZnSe, ZnTe, CdSe, CdTe
    • IV–VI: PbSe, PbTe
    • Alloys: Si1−xGex, AlxGa1−xAs

แบ่งตามความเป็นระเบียบของผลึก

  • Crystalline — เรียงเป็นระเบียบ ระยะไกล ← ใช้ทำอุปกรณ์
  • Polycrystalline — เม็ดผลึกเล็ก ๆ (crystallites) ฝังในเนื้ออสัณฐาน
  • Amorphous — ไม่มีระเบียบระยะไกลเลย
📌 ตัวเลขที่ชอบออก
  • ระดับการโดปทั่วไป = 1 อะตอมโดป ต่อ 10³–10⁸ อะตอม Si
  • ความบริสุทธิ์ที่ต้องการ = สิ่งเจือปนไม่เกิน 1 ใน 10⁹ อะตอม → ต้องทำใน cleanroom
  • Cleanroom class = จำนวนฝุ่นขนาด 0.5 µm ต่อลูกบาศก์ฟุต (class 1, 100, 10,000)
  • อากาศห้องธรรมดา = ฝุ่น >0.5 µm หลายล้านอนุภาคต่อ ft³

1.2 แถบพลังงาน (Energy Bands) — หัวใจของบทนี้

จากอะตอมเดี่ยว → ผลึก

Si มี 14 อิเล็กตรอน: 1s² 2s² 2p⁶ 3s² 3p²
สองชั้นแรกเต็ม = core ยึดแน่นกับนิวเคลียส · เหลือ 4 valence electrons ในชั้นที่ 3 ที่ใช้สร้างพันธะ

อะตอมไกลกัน = ระดับพลังงานแยกกันชัด · พออะตอมเข้าใกล้ ระดับ แตกออก (split) เป็นแถบ แล้ว ซ้อนทับกัน (overlap)
ที่ระยะสมดุลจริงของผลึก Si → เหลือ 2 แถบ คั่นด้วย forbidden gap Eg
ทำไมระดับพลังงานต้องแตก? เพราะ Pauli exclusion principle — อิเล็กตรอน 2 ตัวมีสถานะเหมือนกันเป๊ะไม่ได้ พออะตอม N ตัวมารวมกัน ระดับเดียวกันจึงต้องแตกเป็น N ระดับย่อย ๆ ที่ชิดกันมากจนดูเหมือน "แถบต่อเนื่อง"
การแตกจะ อ่อนกว่า สำหรับอิเล็กตรอนชั้นใน (core) เพราะยึดแน่นกับนิวเคลียส ไม่ค่อยเจออะตอมข้างเคียง

การเติมอิเล็กตรอนในแถบ

อุณหภูมิValence bandConduction bandนำไฟฟ้า?
T = 0 Kเต็ม 100% (4N e⁻ พอดี)ว่างเปล่า❌ ไม่นำ
T > 0 Kมีที่ว่าง = holeมี e⁻ ขึ้นไป✅ นำได้
🔑 เหตุผลเชิงทฤษฎีว่าทำไม band เต็ม = ไม่นำไฟฟ้า "โมเมนตัมสุทธิใน band ที่เต็มเท่ากับศูนย์เสมอ" (net momentum in a full band is always zero)
→ ถึงจะมีอิเล็กตรอนเป็นล้าน ๆ ตัว แต่ทุกตัวมีคู่ที่วิ่งสวนกันหมด → กระแสสุทธิ = 0
ข้อสอบชอบถามประโยคนี้ตรง ๆ

1.3 Hole (โฮล) — พาหะที่ไม่มีตัวตน แต่มีจริง

นิยาม: hole = ที่ว่าง ใน valence band ที่เกิดจากอิเล็กตรอนถูกกระตุ้นขึ้นไป conduction band

มุมมอง Bond picture

พันธะขาดที่ตำแหน่ง 1 → อิเล็กตรอนจากพันธะที่ 2 กระโดดมาเติมตำแหน่ง 1 → พันธะ 1 สมบูรณ์ แต่พันธะ 2 ขาดแทน
ดูเหมือน "รูบวก" เคลื่อนจาก 1 ไป 2

มุมมอง Band picture

อิเล็กตรอนใน VB ย้ายจากสถานะที่ถูกครอบครองไปเติมสถานะว่าง → ทิ้งสถานะว่างอันใหม่ไว้
โมเมนตัมสุทธิใน VB ไม่เป็นศูนย์อีกต่อไป → เกิดกระแสได้

🫧 อุปมาที่อาจารย์ใช้ (จำง่าย ออกสอบได้) hole เหมือน ฟองอากาศในขวดน้ำที่เกือบเต็ม — เวลาเอียงขวด เราสังเกตการเคลื่อนของฟองง่ายกว่าการเคลื่อนของน้ำทั้งขวด และฟองดู "ลอยสวนแรงโน้มถ่วง"

ข้อเท็จจริงเรื่อง hole ที่ต้องจำ

  • ใน intrinsic (บริสุทธิ์): จำนวน e⁻ ใน CB = จำนวน hole ใน VB เท่ากันพอดี (n = p = ni)
  • ต้องปฏิบัติกับ e⁻ และ hole อย่างเท่าเทียม (equal footing)
  • hole มีประจุ บวก → เคลื่อนที่ สวนทาง กับ e⁻ ในสนามไฟฟ้า
  • แต่ กระแสของทั้งคู่ชี้ทางเดียวกัน จึง "บวกกัน" ไม่ใช่หักล้างกัน ← ข้อสอบชอบหลอกตรงนี้!

1.4 Effective Mass (มวลประสิทธิผล) m*

ปัญหา: อิเล็กตรอนในผลึกไม่ได้วิ่งในที่ว่าง มันเจอสนามผลึกที่ซับซ้อนมาก จากไอออนและอิเล็กตรอนตัวอื่นทั้งผลึก

ทางออกอันแสนสวย: แกล้งทำเป็นว่ามันเป็นอนุภาคอิสระ แต่ให้มันมีมวลใหม่ ที่ซ่อนผลของสนามผลึกไว้หมด

สมการการเคลื่อนที่ 3 แบบ — ต่างกันแค่ "มวล" กับ "เครื่องหมาย" ① อิเล็กตรอนอิสระในที่ว่าง : F = −qE = m₀ · dv/dt ② อิเล็กตรอนในสารกึ่งตัวนำ: F = −qE = m*ₙ · dv/dt ③ โฮลในสารกึ่งตัวนำ : F = +qE = m*ₚ · dv/dt
วัสดุm*n/m₀ (อิเล็กตรอน)m*p/m₀ (โฮล)ข้อสังเกต
Si1.180.81e⁻ หนักกว่า hole
Ge0.550.36เบาทั้งคู่
GaAs0.0670.52e⁻ เบามาก → μn สูงมาก!
🔑 จุดเชื่อมโยงข้ามบท GaAs มี m*n = 0.067m₀ (เบาที่สุด) → μn = qτ/m*n สูงที่สุด (8500 cm²/Vs) → เร็วกว่า Si หลายเท่า
ในขณะที่ m*p=0.52m₀ หนักกว่า e⁻ เกือบ 8 เท่า → μn/μp ของ GaAs ต่างกันเกิน 1 order of magnitude (8500 vs 400)
ค่าเหล่านี้เป็น "density of states effective mass" ที่ 300 K และแปรตามอุณหภูมิเพียงเล็กน้อย
⚠️ ค่าคงที่ที่ต้องใช้ q = 1.6×10⁻¹⁹ C · m₀ = 9.11×10⁻³¹ kg (สไลด์เขียน 9.1×10⁻³¹)

1.5 การโดป (Doping) — จุดที่ทำให้สารกึ่งตัวนำมีค่า

ทำไมโดปแล้วเปลี่ยนได้เยอะ? เพราะฐานเดิมต่ำมาก

โลหะ @300K : n ≈ 10²³ cm⁻³ ซิลิกอน @300K : n = p ≈ 10¹⁰ cm⁻³ ← ต่างกัน 10¹³ เท่า!

เติมสิ่งเจือปนแค่ 10¹⁵–10¹⁸ cm⁻³ ก็เปลี่ยนความนำไฟฟ้าไปหลายล้านเท่าแล้ว

Donor vs Acceptor

Donor (ผู้ให้) — หมู่ V

ตัวอย่าง: P, As, Sb

มี valence electron 5 ตัว → ใช้สร้างพันธะแค่ 4 → เหลือ 1 ตัว ที่ยึดแบบหลวม ๆ
ที่อุณหภูมิห้อง e⁻ ตัวนี้หลุดออกไปนำไฟฟ้าได้ → เพิ่ม ความหนาแน่นอิเล็กตรอน
→ ได้ n-type

ในแผนภาพแถบ: สร้าง donor level อยู่ใต้ Ecนิดเดียว

Acceptor (ผู้รับ) — หมู่ III

ตัวอย่าง: B, Al, Ga, In

มี valence electron 3 ตัว → สร้างพันธะได้ไม่ครบ → เหลือพันธะขาด 1 อัน
อุณหภูมิห้อง e⁻ ข้างเคียงกระโดดมาเติม แต่ก็ทำให้พันธะเดิมขาดแทน → hole เคลื่อนที่
→ ได้ p-type

ในแผนภาพแถบ: สร้าง acceptor level อยู่เหนือ Evนิดเดียว

ทำไม dopant level ถึงตื้น? (Pseudo-hydrogen atom)

อิเล็กตรอนส่วนเกินของ donor โคจรรอบแกนที่มีประจุบวกสุทธิ +1 → เหมือนอะตอมไฮโดรเจนเลย! เลยเอาสูตร ionization energy ของไฮโดรเจนมาใช้ได้

ไฮโดรเจนจริง E_ion = m e⁴ / (8 ε₀² h²) = 13.6 eV Donor ใน Si — แก้ 2 ที่: ใช้ m*ₙ แทน m และใส่ ε_r ของ Si E_ion = m*ₙ e⁴ / (8 (ε_r ε₀)² h²) ≈ 0.1 eV (m*ₙ = 1.18 m₀, ε_r = 11.8)

เหตุผลที่ค่าลดลงมหาศาล: εr อยู่ในส่วนกำลังสอง (11.8² ≈ 139) → สนามคูลอมบ์ถูกกำบัง (screened) โดยผลึก → ยึดหลวมกว่าเยอะ

→ ที่อุณหภูมิห้อง (kBT ≈ 26 meV) กระตุ้น dopant ได้ง่ายกว่ากระตุ้นข้าม gap มหาศาล
→ จึง สมมติได้ว่า dopant ionize 100% ที่ 300 K ← สมมติฐานนี้ใช้ตลอดทั้งวิชา!
ข้อควรระวัง: ในการทดลองจริง ค่าพลังงานยึดเหนี่ยวยังเล็กกว่าที่ประมาณจากสูตรไฮโดรเจนอีก

1.6 ผลของอุณหภูมิ — กราฟ 3 ช่วง (ต้องวาดเป็น!)

ความหนาแน่นอิเล็กตรอนของ Si ที่ ND=10¹⁷ cm⁻³ เทียบกับ 1/T
ช่วงอุณหภูมิเกิดอะไรn เท่ากับ
Freeze-outต่ำมาก (→0 K)ไม่มีพลังงานพอกระตุ้นแม้แต่ dopant → dopant ยังไม่ ionize→ 0 (เป็นฉนวน)
Extrinsicรวมอุณหภูมิห้องdopant ionize ครบ 100% แต่ยังไม่พอกระตุ้นข้าม gapn ≈ ND (ราบเรียบ!)
Intrinsicสูงมากe⁻ ข้าม gap เยอะจน ท่วม (swamp) พาหะจาก dopantn ≈ ni(T) พุ่งชันมาก
⚠️ กับดักข้อสอบ "ทำไมช่วง extrinsic กราฟถึงราบ ทั้งที่อุณหภูมิเพิ่ม?"
ตอบ: เพราะ dopant ionize ครบ 100% ไปแล้ว → เพิ่มอุณหภูมิก็ไม่มีพาหะเพิ่มอีก (แหล่งหมดแล้ว) และ ni ยังน้อยเกินกว่าจะมีนัยสำคัญ

"ที่อุณหภูมิสูงมาก ๆ สาร extrinsic จะเป็นยังไง?"
ตอบ: มันจะเหมือนสาร intrinsic เพราะพาหะจาก gap ท่วมพาหะจาก dopant → คุณสมบัติที่เราออกแบบไว้หายหมด (นี่คือเหตุผลว่าทำไมอุปกรณ์ Si ทำงานได้ถึงแค่ ~150–200°C แต่ SiC/GaN ที่ Eg ใหญ่กว่าไปได้ร้อนกว่า)

  5. hole คืออะไร มีประจุอะไร เคลื่อนที่ทางไหนเทียบกับ e⁻ แล้วกระแสของทั้งคู่บวกหรือหักล้างกัน
